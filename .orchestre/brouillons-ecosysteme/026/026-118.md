2. **`app/api/pubs/commander/route.ts`** (`runtime = 'nodejs'`, `dynamic = 'force-dynamic'`), dans cet ordre :
   - `if (!actif('packPub')) return new NextResponse(null, { status: 404 })` en première instruction ;
