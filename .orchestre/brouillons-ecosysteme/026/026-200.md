## Contexte

**Ce qui manquait** (contre-revue du 25/09 au soir) : un pack payé ne se fabriquait que poste allumé, lancé à la main (026-156, 026-157), et un échantillon du Studio dans une séance de Claude Code (026-155), avec des outils sans droit commercial (ElevenLabs en formule gratuite). Benj ne prend que les appels et les paiements ; la production passe par l'usine ; l'abonnement Claude est à épargner. Cette fiche fait tourner **la fabrication sur l'usine**, par le modèle déjà éprouvé de l'Atelier (026-097) et du livreur (026-056) : un jeton d'agent, des adresses signées, et la vérification côté Vercel.

**L'agent** : `livreur_usine` (semé par 0110, 026-054 ; son jeton est déjà dans le coffre, 026-143). Le livreur de l'usine livre aussi les packs et les échantillons : aucune graine nouvelle, aucune migration.

**La chaîne gratuite** (B3, 026-128, 026-155, 026-158 réécrites) : la vraie photo (celles de l'artisan pour un pack, celle de la page produit de la marque, après son accord écrit, pour un échantillon) ; HyperFrames en local ; la voix `ff_siwis` (Kokoro, `hyperframes tts`) ; des fonds FLUX.1 [schnell] facultatifs pour le Studio (par Cloudflare Workers AI, Apache-2.0 ; jamais le produit, jamais une personne ; [à vérifier le jour de la fiche : la route et la clé que freellmapi expose pour les images, sinon pas de fond, un aplat]) ; **aucun modèle vidéo, aucun outil payant**.

**Les juges** sont écrits avant (026-199, `usine-pubs-qa`) : lire leur cahier (UP-1 à UP-10) avant d'écrire une ligne.

## Ce qu'il faut faire

1. **`lib/pubs/usinePubs.ts`**, pur (aucune E/S) : `LIMITES` (pack : trois MP4 et trois visuels, `video/mp4`, `image/jpeg`, `image/png`, 60 Mo par fichier ; Studio : un MP4 de 3 Mo) ; `cheminPermis(travail, chemin)` (seulement `packs-pubs/<pack>/livraison/<nom>` ou `packs-pubs/studio/<marque_cle>/echantillon-<n>.mp4`, noms en `^[a-z0-9][a-z0-9._-]{0,80}$`, ni `..` ni `//`) ; `octetsMagiques(type, debut)` ; `extraitAccord(texte)` (400 signes au plus, adresses et numéros masqués).
2. **`app/api/usine/pubs/travail/route.ts`** (`GET`, `runtime = 'nodejs'`, `dynamic = 'force-dynamic'`) : `if (!actif('busAgents'))` → 404 avant toute identité ; `authAgent(req)` et l'agent `livreur_usine` seul (sinon 403) ; `ops_battement('livreur_usine')` ; `pauseGenerale()` active → `{ travail: null }` ; sinon, dans cet ordre, le plus ancien pack `payee` sans bail (bail de 90 min posé en base par une mise à jour conditionnelle, [à vérifier : la colonne de bail de `packs_pubs` ; sinon, un bail dans la ligne `verifications`]) → `{ type: 'pack', id, pack, photos: [{ nom, url }] }` (le `pack.json` d'`exporter.mjs`, sans courriel ni téléphone ; des adresses signées de lecture de 600 s) ; sinon la plus ancienne décision `studio_echantillon` accordée et sans échantillon → `{ type: 'studio', decision, marque_cle, page_produit, accord: { message_id, recu_le, extrait }, echantillons_refuses }`, seulement pour une marque sans opposition ni refus ; sinon `{ travail: null }`.
3. **`app/api/usine/pubs/depot/route.ts`** (`POST`) : mêmes gardes ; corps `{ travail, fichiers: [{ chemin, type, taille }] }` ; chaque chemin passé par `cheminPermis` et `LIMITES` (sinon 400, aucune adresse) ; stockage (`ops_stockage_octets()`) au-delà de 60 % ou non mesurable → 507 ; sinon une adresse signée de dépôt par fichier (`createSignedUploadUrl`).
4. **`app/api/usine/pubs/rendu/route.ts`** (`POST`) : mêmes gardes ; corps `{ travail, ok, fichiers: [{ chemin, sha256 }], juge: { nom, code, empreinte_journal }, raison? }` ; `ok: true` → la route **relit chaque fichier** dans le stockage, vérifie sa taille, son SHA-256 et ses octets magiques, et exige `juge.code === 0` avec le bon nom (`pub-locale-qa` pour un pack, `pub-qa` pour un échantillon) ; puis :
   - pack : `payee` → `fabriquee`, avec `fabrique_le` et `verifications` (la même écriture que `scripts/pack-pub/deposer.mjs`, 026-157), bail levé ;
   - échantillon : la décision `studio_echantillon` tranchée en `depose` (le même effet que `deposer-echantillon.mjs`, 026-166), **sauf le premier du Studio** : une décision `regarder_premier_echantillon` pour Benj (options `envoyer` et `refaire`, l'aperçu par un lien signé de 10 min), et `depose` seulement au rendu qui suit son « envoyer » ;
   - `ok: false`, ou une vérification qui échoue → rien ne change hors le compteur d'échecs du travail (dans `verifications` du pack, ou dans la décision de l'échantillon) ; au 3e échec, plus de reprise automatique : le pack reste `payee`, visible avec ses échecs dans l'écran Packs du Poste (026-147), et le repli du poste s'applique (026-157) ; aucun motif d'alerte nouveau ; `{ ok: false, raison }`.
5. **`scripts/usine/pubs.mjs --une-passe [--base=<url>]`**, sur l'usine (Node, ESM, `--import ./scripts/ts-loader.mjs`), sous le compte `agents`, lancé par `avec-coffre.mjs` avec `PRESTI_JETON_LIVREUR_USINE` :
   - un verrou par travail (`~/presti-pubs/verrous/<id>.lock`, créé en `wx`) ;
   - **pack** : télécharger les photos dans `~/presti-pubs/<pack>/` (0700), écrire `pack.json` ; si le pack a une voix de synthèse, `hyperframes tts --voice ff_siwis` **avant** la fabrication, puis la normaliser seule (`loudnorm=I=-14:TP=-1.5:LRA=11`) ; `node scripts/pack-pub/fabriquer.mjs <dossier>` ; `node scripts/pub-locale-qa.mjs --partie=complet <dossier>` **vert avant tout dépôt** ; puis `depot`, les envois par les adresses signées, `rendu` avec les empreintes et l'empreinte du journal du juge ;
   - **échantillon** : construire le vault temporaire `~/presti-studio/<marque_cle>/` (0700) : `SaaS/Studio/prealables.md` copié de `docs/studio/prealables.md` du code déployé, un `registre-refus.csv` vide (la route ne rend pas une marque refusée), `marques/<cle>/accord-photos.md` (l'extrait, le Message-ID et la date rendus par la route), la page produit copiée datée (`page-produit-AAAA-MM-JJ.html`, lue avec les règles du Lecteur : `robots.txt`, `UA_RECENSEUR`, 1 requête par seconde) et `produit.jpg` (l'image principale de la page) ; `node scripts/studio/garde.mjs --marque=<cle> --vault=<ce dossier>` (code 3 → rien d'autre, `rendu` en échec avec la raison) ; le script de démonstration par `creerLecteur('studio')` de `lib/agents/llm.ts` (026-043), **sur la seule page produit** (jamais l'accord, l'adresse ni le Message-ID), JSON validé au contrat de `script.json` (allégations avec leur extrait, `presentateur_virtuel: false`) ; les fonds facultatifs ; `hyperframes tts --voice ff_siwis` ; `node scripts/studio/monter.mjs <echantillon>` ; `node scripts/pub-qa.mjs <echantillon>` **vert avant tout dépôt** ; puis `depot`, l'envoi, `rendu` ;
   - pannes : bus ou stockage injoignable → une ligne de journal, code 0, aucune exception ; `hyperframes` ou `ffmpeg` absent → `rendu` en échec `outil_absent` ;
   - n'affiche que des identifiants et des comptes : jamais un texte de réponse, une adresse, un numéro ni le jeton ; n'écrit que sous `~/presti-pubs/`, `~/presti-studio/` et un dossier temporaire du passage, effacé à la fin (les dossiers de travail sont purgés 30 jours après le rendu).
6. **Les unités** (installées par 026-202, jamais par cette fiche) : `presti-pubs.service` (`Type=oneshot`, `User=agents`, `WorkingDirectory=/srv/presti-agents`, `Environment=CODEX_LANCEUR=/usr/local/bin/presti-ia-modele`, aucun `EnvironmentFile=`, `MemoryMax=4G`, `Nice=10`, `TimeoutStartSec=80min`, `ExecStart=/usr/bin/node scripts/usine/avec-coffre.mjs PRESTI_JETON_LIVREUR_USINE -- /usr/bin/node --import ./scripts/ts-loader.mjs scripts/usine/pubs.mjs --une-passe`) et `presti-pubs.timer` (toutes les 15 min, `Persistent=true`).
