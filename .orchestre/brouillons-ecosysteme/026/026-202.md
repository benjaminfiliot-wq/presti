## Contexte

La fabrication des packs et des échantillons est écrite et jugée sur doublures (026-200, 026-199). Il reste à la faire tourner sur l'usine, et à le prouver sans le poste. Les outils : **HyperFrames** (CLI, rendu par Chromium ; `hyperframes tts` et sa voix `ff_siwis`, dont le modèle Kokoro se télécharge au premier usage), **ffmpeg** (installé pour l'Atelier, 026-075, 026-143), **Chromium arm64** (026-143). Aucun outil payant.

**Les préalables du Studio** (026-128, 026-155) vivaient dans le vault du poste (`SaaS/Studio/prealables.md`) ; le tourneur de l'usine les lit dans le code déployé : Claude Code tient donc leur **copie** dans `docs/studio/prealables.md` (des dates et des lectures, aucune donnée personnelle) : la chaîne gratuite et ses licences (Kokoro `ff_siwis`, FLUX.1 [schnell], sorties de Cloudflare Workers AI, HyperFrames), la fiche ARPP, l'activité de l'EI lue dans l'extrait public du RNE et confirmée par Benj.

## Ce qu'il faut faire

1. **Gestes de Benj**, un par un : (a) « oui » à l'installation des outils de rendu sur l'usine (téléchargement de HyperFrames 0.8.33 par `npm` dans `/srv/presti-agents` sans script d'installation, et du modèle de voix au premier `hyperframes tts` : Claude Code donne le nom, la source et la taille avant) ; (b) « oui » au minuteur `presti-pubs` ; (c) confirmer d'un mot l'activité de l'EI que Claude Code a lue dans l'extrait public du RNE ; (d) pour l'épreuve, éteindre le poste au moment convenu, puis le rallumer.
2. **`docs/studio/prealables.md`** : Claude Code lit les licences et conditions de la chaîne gratuite et la fiche ARPP, écrit les lignes datées au format de 026-128 (« Chaîne gratuite lue le … — … — droit commercial : oui|non », « Fiche ARPP lue le … », « Activité déclarée le … »), puis les recopie à l'identique dans `SaaS/Studio/prealables.md` du vault (la garde du poste, en repli, lit celle-là) ; une licence qui refuse l'usage commercial → « droit commercial : non », la garde refusera, et Benj est prévenu le jour même.
3. **Les outils**, par `gardien` : vérifier `ffmpeg -version` et Chromium ; installer HyperFrames 0.8.33 dans l'arbre déployé si `npx --yes hyperframes@0.8.33 --version` ne répond pas sous `agents` [à vérifier le jour J : que le CLI tourne sous Linux arm64 ; sinon, s'arrêter et le noter : les packs restent au repli du poste] ; sous `agents`, un `hyperframes tts --voice ff_siwis` d'essai sur une phrase fictive rend un fichier audio non vide ; un `hyperframes render` du gabarit témoin de 026-126 rend un MP4 ; noter les versions dans `mise-en-service.md`.
4. **Le minuteur**, par `gardien` : copier `presti-pubs.service` et `presti-pubs.timer` de `/srv/presti-agents/scripts/usine/systemd/` dans `/etc/systemd/system/`, `systemd-analyze verify`, `daemon-reload`, `systemctl enable --now presti-pubs.timer` ; noter l'empreinte des unités installées.
5. **L'épreuve PC éteint** : `node --import ./scripts/ts-loader.mjs scripts/usine-pubs-qa.mjs --reel --etape=preparer` (le pack d'essai et l'échantillon d'essai posés en production, marqués `essai-pubs-<aléa>`), Benj éteint le poste au moins 2 h, puis `--etape=conclure` au rallumage (UP-R), qui fait tout le ménage dans un `finally`.
6. **`docs/agents/usine-pubs.md`**, pour Benj et pour la reprise : ce qui tourne (un pack payé est fabriqué dans les 2 h, un échantillon accordé aussi) ; ce qu'il voit (les cinq premiers packs à livrer, le premier échantillon à regarder) ; le repli du poste (`scripts/pack-pub/exporter.mjs`, `fabriquer.mjs`, `deposer.mjs`, `scripts/studio/deposer-echantillon.mjs`, par Claude Code avec son accord, si l'usine est injoignable plus de 24 h) ; comment arrêter (`systemctl stop presti-pubs.timer`, par `gardien`, sur son ordre) ; aucune valeur de jeton.
7. **Ne pas faire.** Aucune installation sous le compte `usine` ; aucun outil payant ; jamais d'envoi d'un échantillon d'essai ; aucune écriture en production hors les objets d'essai, effacés dans le `finally`.
