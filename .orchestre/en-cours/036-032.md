# 036-032 — Le vrai multi-agents dans n8n, et la preuve de la clé

## Ton rôle
Tu es l'architecte des agents n8n de Presti : tu installes dans n8n ce que les fichiers décrivent, sans rien envoyer.

## Avant d'agir
- Lis l'audit `plans/011-cadrage-01-11/p6-signature/audit-0311-conformite.md` (écart 2), puis :
  - `plans/011-cadrage-01-11/p6-signature/outillage/multi-agents.md` ;
  - les exports de `.orchestre/preuves/036-019/` (organigrammes, gabarits) ;
  - le journal `journal-mise-en-service.md` (036-024, 036-025, 036-027) ;
  - `branchement-reel.md` (036-030, qui vient de brancher les vraies lectures).
- n8n-first. Relis chaque workflow dans n8n avant de le toucher. Utilise `get_workflow_sdk_reference`, puis `get_workflow_best_practices`
  (agents), puis `validate_node_config`.

## À faire
1. **Chaque chef** (`presti-dep-accueil`, `-devis`, `-suivi`, `-facturation`, `-apres`, `-operations`, `-direction`) reçoit un nœud agent
   IA. Ce nœud porte :
   - Claude Sonnet 5.5, identifiant « Anthropic account » ;
   - un parseur de sortie strict ;
   - jamais un montant inventé : les montants restent calculés par le code ;
   - ses spécialistes en outils (`toolWorkflow` vers les `lib-*` publiés, chacun avec `callerIds` ouvert au chef) ;
   - plafond de sortie suffisant et réflexion réglée, comme 036-027.

   La logique de décision qui marche (cartes, porte, pilote) reste ; l'agent s'y ajoute, il ne la remplace pas.
2. **Republier, enfants d'abord.** Rejoue les bancs (`presti-banc-cerveau`, `-argent`, `-suivi`, `-apres`, `-operations`, `-direction`),
   une fois chacun, porte « simulation » à vrai. Relis-les nœud par nœud. Deux échecs : dépublie, parents d'abord, et écris pourquoi.
3. **La clé.** Prouve, par `presti-banc-boite` ou par l'exécution d'un `lib-boite-*` en simulation, qu'un nœud Code lit
   `$env.BOITE_CLE_N8N`. La clé a été posée le 03/11 à 19 h 30. Ne l'affiche jamais : seule sa longueur, 44 signes, peut apparaître.
   - Si n8n bloque l'accès (`N8N_BLOCK_ENV_ACCESS_IN_NODE`), écris-le avec l'erreur exacte.
   - Ne change pas ce réglage du serveur : il revient à la session principale.
4. **`multi-agents-n8n.md`** : pour chaque chef, le nœud agent, ses outils, le banc, l'exécution, le résultat et le retour arrière ; puis la
   preuve de la clé.
