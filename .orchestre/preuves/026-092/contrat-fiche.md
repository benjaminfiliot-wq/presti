## Contexte

La station `/controle/station` (rectification §4) se lit par **une seule route**, par vues, comme la route des blocs du Pilotage (026-068, dont elle reprend l'enveloppe et la garde) :
- `direct` : la barre, l'équipage, Attention, le Commandement, les tapis et le bandeau, **en un appel**, toutes les 30 s (une sous-partie en panne se voit sans vider l'écran) ;
- `fil` : le journal de bord, toutes les 5 s, seulement ce qui est plus récent que le dernier événement reçu (`apres`) ;
- `salle` : le panneau d'une salle, quand il est ouvert ;
- `agent` : la fiche d'un agent (écran 3, §4.4), quand elle est ouverte.

Le Chef, lui, tient la réunion quotidienne (§4.6) depuis l'usine Oracle, avec son jeton d'agent : il ouvre la réunion, lit les chiffres rassemblés **sans modèle** par la base, puis clôt la réunion avec son compte rendu, son objectif et ses idées, ou l'abandonne. Deux routes du bus lui servent, sur le modèle de 026-042 (`authAgent` de `lib/agents/garde.ts`, 026-040). Elles s'ouvrent seulement si les deux drapeaux sont levés (`busAgents` et `pilotage`).

**La règle de vérité** (§4.0) s'applique d'abord ici : **aucun calcul, aucun tri et aucun seuil dans la route ni dans `station.ts`**. Tout vient des fonctions de la base (lues par `rpc`) et des modules purs (026-015, 026-017, 026-070), jamais recopiés. Les montants d'argent ne passent pas par ici : l'écran les lit sur `GET /api/controle/tresorerie` (026-059).

Ce qui existe et se réutilise :
- la garde : `estFondateur(req)` puis `exigerDomaine(f, 'sante', 'voir')` (`lib/direction/garde.ts:40-75`) ; `authAgent` (026-040) pour les routes du Chef ;
- l'enveloppe : `sourcer(cle, source, f)` rend `{ valeur, source, a, cache, erreur? }` sans jamais lever (`lib/direction/fraicheur.ts:29-43`) ; `nonMesure` (`:46`) ;
- `pauseGenerale()` (`lib/agents/pause.ts`, 026-044) ; `validerSnapshot` (`lib/pilotage/code.ts`, 026-017) ;
- les alertes non acquittées : table `alertes` (`motif`, `gravite`, `cree_le`, `acquittee_le`), comme `app/api/controle/a-faire/route.ts:27-31` ; les commandes : `sites_commandes` (0088, 0103) ; les achats : `achats` (0071 : `fournisseur`, `libelle`, `categorie`, `date_facture`, `ttc_cents`).
