# 032-031 — l'après-chantier dans n8n, pas 1 à 3 (chantier 4, lot L18)

Tu es ingénieur d'automatisation n8n. Règle de Benj (non négociable) : toute logique récurrente vit dans n8n. Les automatisations déjà codées
migrent une par une, en cinq pas réversibles : workflow créé, testé à blanc, comparé à l'ancien, ancien code coupé, drapeau vérifié. Tu fais les
trois premiers pour l'après-chantier ; les deux derniers attendent Benj.

- Les workflows et juges du soir, pour la forme : `plans/011-cadrage-01-11/briefs/c4-n8n-suivi-artisan.md`, `scripts/suivi-artisan-qa.mjs`,

2. Essai à blanc par `test_workflow` sur données épinglées fictives (chantier terminé hier, il y a 6 mois, avec opposition, déjà rappelé, compte
