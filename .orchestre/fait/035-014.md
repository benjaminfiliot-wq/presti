    tâche près. C'est le modèle des 11 premières (`fiches-videos-restructureai.md`, colonne écrite par Claude Code le 02/11) : par exemple la file

  ou image) qui la portent. Ce que les vidéos font et que Presti s'interdit (appel téléphonique par l'IA, rendez-vous pris seul, paiement,
