# 032-020 — la sauvegarde de toutes les tables (chantier 4, lot L9, phase 0)

## Ton rôle

Tu es l'ingénieur fiabilité de Presti. La sauvegarde ne couvre que 34 tables sur environ 92 et ne tourne plus depuis le 25/10 : sans elle,
aucune migration ne peut partir. Tu la rends complète et prouvée hors ligne ; tu ne touches jamais à la vraie base.

## À lire

- Le plan du chantier 4 (`plans/011-cadrage-01-11/chantier-4-assistant-plan.md`) §4.1 (constat, les trois pas, ce qui attend Benj, la preuve
  exigée avant toute migration) ; `plans/011-cadrage-01-11/cadrage-p3.md:100-120` ; le script actuel `scripts/sauvegarde.mjs` (sa liste
  figée l.49-59, son chiffrement par `cle-sauvegarde.pub.pem`) ; `.claude/rules/migration-production.md`.

## À faire

1. `scripts/sauvegarde.mjs` découvre les tables par la définition OpenAPI de PostgREST (`GET /rest/v1/` ; doublure dans les essais) ;
   `EXCLUES` donne la raison de chaque table écartée (comme `HORS_LANCEUR`) ; la restauration suit l'ordre des clés étrangères (les
   parents d'abord) ; les buckets restent ; le chiffrement et le manifeste (tables, comptes, empreintes) restent ; `--verifier` relit une
   archive et compare les comptes.
2. `scripts/sauvegarde-qa.mjs`, hors ligne, sur une doublure PostgREST fictive : toutes les tables découvertes entrent ; une table nouvelle
   entre sans changer le code ; une table écartée sans raison fait rougir ; l'ordre de restauration respecte des clés étrangères fictives ;
   une archive tronquée échoue à `--verifier` ; des mutants (liste figée remise, ordre inversé, comptes non comparés) rougissent.
3. Dans `resume.md`, la commande exacte du vrai passage, que la session principale lancera depuis le PC :
   `node scripts/sauvegarde.mjs --dossier D:/presti-travail/sauvegardes/base` puis `--verifier`.

Avant de commencer : `regles_pour` (MCP `cerveau`) sur « sauvegarde, migration, données ». Aucune donnée réelle ; aucun secret lu ni affiché.

## Fin

`node scripts/orchestre.mjs verifier 032-020` vert, `resume.md`, tâche dans `fait/`. Dernière ligne : `TACHE 032-020 FAITE`.
