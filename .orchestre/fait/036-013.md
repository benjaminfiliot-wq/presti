## À construire (dans n8n d'Oracle, par le MCP `n8n-oracle`)

`gabarit-artisan-accueil` (un workflow, ou plusieurs `gabarit-artisan-accueil-*` si la lisibilité l'exige) :

**Entrées** :
- déclencheurs à intervalle Gmail, Outlook et IMAP ;
- un déclencheur horaire qui lit les événements de la plateforme : page `/p`, WhatsApp, Telegram, Messenger, Instagram, SMS. Ils arrivent par
  Presti, pas par n8n, qui n'est pas exposé (OUTILLAGE O2) ;
- Facebook Lead Ads par l'API Graph (nœud Facebook Graph, lecture) ;
- les e-mails de notification des plateformes de devis.

**Dépôt d'abord dans la plateforme** : même conversation par client, canal d'origine gardé, un doublon reçu par deux canaux ne crée pas deux
conversations (p6:280-285).

**Spécialistes en agents IA** (Qualificateur, Rédacteur) :
- AI Agent 3.x, modèle Claude (`claude-haiku-5-5`), un seul parseur structuré, sortie revalidée par un nœud Code ;
- **outils de lecture seulement** : fil Gmail ou Outlook, `lib-trier-demande` en outil (« outil: lecture »), lecture de photo par le nœud
  Anthropic ;
- le tri et les décisions restent ceux de `presti-dep-accueil` : le gabarit l'appelle, il ne réécrit pas la logique.

**Écritures, toutes derrière la porte « simulation »** :
- brouillon Gmail ou Outlook (Studio) ;
- réponse Gmail, Outlook, SMTP, WhatsApp, Telegram, ou Messenger et Instagram par l'API Graph, seulement en Signature pour le type
  `reponse_prospect` activé ;
- carte « À valider » et journal (HTTP Supabase, filtre du compte, R14) ;
- marque blanche : la réponse part au nom de l'artisan, jamais « Presti » ;
- mention de l'assistant sur ce qui part après le modèle (R20).

**Réglages** :
- inactif, aucun identifiant (R21) ;
- workflow d'erreur commun, Europe/Paris, délai borné, politique d'appel ;
- notes sur chaque nœud d'outil (ce qu'il lit, ce qu'il écrirait chez le client).

**Essais** : `test_workflow` en simulation, données épinglées fictives (« Exemple. »), au moins :
- Studio : un e-mail donne un brouillon et une carte ;
- Signature avec le type activé : un envoi prévu ;
- Signature sans le type : une carte ;
- un spam ;
- un doublon reçu par deux canaux.

## Le juge `scripts/gabarits-accueil-qa.mjs` (hors ligne, mutants obligatoires)

- **Structure** :
  - chaque outil de la ligne Accueil du § 5 a son nœud ;
  - l'agent a Claude, un parseur, des outils de lecture ;
  - aucun effet n'est atteignable sans la porte ;
  - aucun identifiant, aucun webhook.
