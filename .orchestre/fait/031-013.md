# 031-013 — la file n8n lance aussi Claude Code par Orca

## Ton rôle

Tu es un spécialiste des systèmes agentiques d'automatisation (n8n, Orca, Hermes, Claude Code) et de leur sûreté.

## Ce que Benj a demandé

- « De lancer un agent sans passer par Orca » est interdit ; n8n porte toutes les automatisations (`.claude/rules/architecture-outils.md`,
  ADR-001 et ADR-002 du vault). Le 02/11 au matin, Benj a demandé que Claude Code passe aussi par Orca, dans une conversation visible.
- Vidéo metakaihos (`plans/analyse-videos.md:1368-1475`) et contrôle croisé du 02/11 : une relecture hebdomadaire des notes
  « à revoir », faite par Claude Code et jamais par Hermes (brief `plans/011-cadrage-01-11/briefs/revoir-notes.md`).

## À faire

1. `scripts/hermes-tache-n8n.mjs` : la liste blanche dit, pour chaque tâche, son exécutant (`hermes` par défaut ; `claude` pour
   `revoir-notes`) ; ajouter `revoir-notes` → `plans/011-cadrage-01-11/briefs/revoir-notes.md`, exécutant `claude`. `--precheck`,
   `--prendre` et `--fini` ne changent pas de contrat.
2. `scripts/lancer-hermes-file.mjs` : selon l'exécutant de la tâche en tête de file (lu par `--precheck` ou un peek, sans la
   prendre), lancer `orca agent launch --agent hermes …` comme aujourd'hui, ou `orca agent launch --agent claude --model
   claude-sonnet-5-5 --effort high --surface terminal --prompt <consigne> --json` ; même passage, même consigne de prise et de fin,
   même registre d'onglets, mêmes sorties sans titre ni sortie brute d'orca.
3. `revoir-notes.md` : lignes de commande alignées (`--prendre --passage=<…>`, `--fini`).
4. Banc `scripts/hermes-file-banc.mjs` : scénarios « tâche Claude → onglet Claude », « tâche Hermes → onglet Hermes », « tâche
   inconnue → écartée », et un mutant par garde ; le scénario S12 (liste blanche) suit la nouvelle forme.
