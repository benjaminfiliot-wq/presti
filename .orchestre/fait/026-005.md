## Ce qu'il faut faire

1. **La commande.** `node scripts/instantane-quotidien.mjs [--pousser | --sans-pousser] [--racine=<dépôt>] [--depot=<url ou chemin>] [--vault=<dossier>]`.
   - `--racine` vaut par défaut la racine de presti.
   - `--depot` vaut par défaut l'URL du dépôt de sauvegarde, ou `PRESTI_SAUVEGARDE_DEPOT` si cette variable existe.
   - `--vault` vaut par défaut la clé `vault` de `.orchestre/orchestre.json`, résolue depuis la racine.
   - Sans `--pousser`, rien ne part.
2. **L'instantané.** Même méthode que `instantane()`, copiée ici et non importée (`antigravity.mjs` va déménager). Référence locale : `refs/instantanes/quotidien-<horodatage>`. L'index temporaire est supprimé dans un `finally`.
3. **Ce qu'on exclut, avant `write-tree`**, par `git rm --cached -q -- <chemin>` **sur l'index temporaire seulement**. On ne scanne que les fichiers qui diffèrent de HEAD (modifiés ou non suivis) : HEAD est déjà sur `origin`.
   - Les fichiers de plus de 90 Mo (GitHub refuse au-delà de 100 Mo) : motif `taille`.
   - Les fichiers où `chercherSecrets` trouve un motif : motif = nom du motif. Il faut exporter `MOTIFS_SECRETS` (tableau `{ nom, re }`) et `chercherSecrets(texte)`, qui rend les noms trouvés, jamais les valeurs. Les motifs :
     - `stripe` : `sk_live_`, `rk_live_` ou `sk_test_`, suivi de 20 signes alphanumériques au moins ;
     - `stripe_webhook` : `whsec_` ;
     - `anthropic` : `sk-ant-` ;
     - `resend` : `re_` suivi de 20 signes au moins ;
     - `supabase_service` : un JWT `eyJ…` dont la charge décodée contient `"role":"service_role"` ;
     - `cle_privee` : `-----BEGIN [A-Z ]*PRIVATE KEY-----` ;
     - `google` : `AIza` suivi de 35 signes ;
     - `github` : `ghp_` ou `github_pat_` ;
     - `env` : un fichier nommé `.env` ou `.env.*`, sauf `.env.local.example`.

     Les fichiers binaires, qui contiennent un octet nul dans les 8 premiers Kio, ne sont scannés que par leur nom.
   - Les fichiers qui contiennent une donnée de prospect : motif `prospect`. On lit dans le vault `Prospection/deja-contactes-email.txt` et `Prospection/deja-contactes-instagram.txt` (une entrée par ligne, 4 signes au moins, comparaison sans casse). On lit aussi `Prospection/phase0/suivi.csv` s'il existe : colonne dont l'en-tête contient « prospect ». Un vault absent n'arrête rien et le journal le dit (`vault: 'absent'`).
   - Plus de 20 fichiers exclus : on ne pousse pas et on sort en code 1. C'est une anomalie à regarder.
4. **L'envoi.** `git push <depot> <commit>:refs/heads/instantane-<AAAA-MM-JJ>`, à la date de Paris (`Intl.DateTimeFormat` avec `Europe/Paris`).
   - Si la branche existe déjà (`git ls-remote`), on pousse `instantane-<AAAA-MM-JJ>-<HHMM>`.
   - Jamais `--force`, `-f`, `+`, `--mirror`, `--all` ni `--tags`, et aucune autre référence que ce commit.
   - Puis on relit : `git ls-remote <depot> refs/heads/<branche>` doit rendre le commit.
5. **Les invariants**, contrôlés par le script lui-même avant de sortir, avec le code 1 s'ils sont violés : le HEAD, `git status --porcelain` et l'empreinte de `.git/index` sont identiques avant et après.
6. **Le journal.** Une ligne JSON par passage dans `<racine>/.orchestre/travail/sauvegardes.jsonl` (dossier ignoré par git) : `{date, commit, branche, fichiers, octets, exclus: [{chemin, motif}], vault, ok}`. Jamais une valeur de secret, ni dans le journal ni dans la sortie.
7. **Les codes de sortie.**

   | Code | Sens |
   |---|---|
   | 0 | instantané poussé, rien exclu |
   | 4 | poussé, avec des exclusions |
   | 1 | échec : scan, envoi, invariant, ou plus de 20 exclusions |
   | 2 | usage |

   La dernière ligne de la sortie commence par `ALERTE BENJ :` si le code est 1.
8. **Importer le script n'exécute rien.** Le programme principal ne tourne que si le fichier est lancé directement, par comparaison de `import.meta.url` et `process.argv[1]`.
9. **`docs/sauvegardes.md`** : ajouter une section « Le code et l'arbre de travail ». Elle dit :
   - ce qui part : l'arbre sans ce qu'ignore `.gitignore` ;
   - ce qui est exclu, et pourquoi ;
   - où ça va, quand ça part, et que rien ne part PC éteint ;
   - comment récupérer : `git fetch https://github.com/benjaminfiliot-wq/presti-sauvegarde.git instantane-AAAA-MM-JJ`, puis `git show FETCH_HEAD:<chemin>` ;
   - que le journal est `.orchestre/travail/sauvegardes.jsonl`.
10. **À ne pas faire.** Ne toucher ni à `main`, ni à l'index réel, ni à l'arbre de travail. Ne créer aucune branche locale. Ne rien supprimer : pas de `update-ref -d`, pas de nettoyage des anciennes références. Ne pas importer `antigravity.mjs`.
