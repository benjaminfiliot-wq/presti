## Contexte

Un pack pubs payé est une ligne de la table `packs_pubs` à l'état `payee` (colonnes : `id`, `artisan_id`, `email`, `etat`, `matiere`, `fabrique_le`, `verifications`…). Il se fabrique **sur l'usine** (tourneur des pubs, 026-200 : contre-revue du 25/09 au soir) ou, en repli, **sur le poste** (`scripts/pack-pub/fabriquer.mjs <dossier>`, fiche 12), jamais sur Vercel : **ces deux scripts-ci sont le repli du poste et ne tournent pas PC éteint**. Ils lisent la clé de service eux-mêmes dans `.env.local`, sans l'afficher, comme `scripts/site-deposer.mjs:17-25` ; aucun agent ne lit ce fichier.

Modèles :
- `scripts/site-deposer.mjs` : dépôt dans le bucket privé `sites` ; il lit la commande puis lance le juge (`:29-43`) ; marge de 400 Mo sur un stockage partagé de 1 Go (`:26`). **Ici, l'ordre est inverse** : le juge local d'abord, aucun accès réseau tant qu'il n'est pas vert ;
- la mesure exacte de l'occupation, tous buckets confondus : `scripts/promo-heberger.mjs:56-72`, puis le reste après dépôt (`:111`). Le stockage est partagé avec les photos de tous les artisans : un dépassement coupe tout le monde ;
- l'adresse publique d'un artisan : `lib/urls.ts` (`ArtisanAdresse` `:14`, `chemins` `:45-53`) : son domaine vérifié s'il en a un, sinon `https://prestiapp.fr/p/<slug>`.

Le juge d'un pack fabriqué : `node scripts/pub-locale-qa.mjs --dossier=<pack>` (code 0 si conforme).

**La voix.** Quand le pack a une voix de synthèse, `voix.mp3` doit exister dans le dossier avant la fabrication. **Le moteur par défaut est la voix française locale `ff_siwis`** du CLI HyperFrames (`hyperframes tts`, Kokoro ; modèle téléchargé au premier usage ; voie gratuite du 25/09 : aucun achat, et l'offre gratuite d'ElevenLabs n'a pas de licence commerciale), produite par Claude Code à partir du `texte_voix` exact ; sa licence est notée dans le dossier du pack (`licence-voix.md`, 026-156) [à vérifier : licence de la voix et du modèle pour une pub payée]. **ElevenLabs Creative** (choisi par Benj le 24/09 au lieu d'Alexya) ne sert que si Benj a une offre payante qui donne le droit commercial. Ce n'est pas un geste de Benj de choisir le moteur (revue du 24/09, B12), ni de superviser la voix. L'export ne fabrique pas la voix : il la signale, et `voix-a-produire.txt` commence par « voix à produire : ff_siwis ».

Dépend de : 026-110 PASS (juge) et 10 PASS (témoin de fabrication).

## Ce qu'il faut faire

1. **`scripts/pack-pub/exporter.mjs <pack_id> <dossier> [--depuis-fichier=<ligne.json>]`** :
   - lit la ligne (`.eq('id', pack_id)`) et l'adresse de l'artisan (`slug`, `domaine`, `domaine_verifie`) par la clé de service ; `--depuis-fichier` remplace ces deux lectures par un fichier JSON `{ ligne, artisan }` (mode d'essai, sans réseau ni variable) ;
   - refuse une ligne qui n'est pas `payee` (code 1, rien d'écrit) ;
   - écrit `<dossier>/pack.json = { pack_id, matiere, site }`, `matiere` recopiée telle quelle ; jamais l'`email` ;
   - voix de synthèse sans `<dossier>/voix.mp3` : écrit `voix-a-produire.txt` (première ligne « voix à produire : ff_siwis », puis le `texte_voix` exact) et sort en code 4 ;
   - n'écrit jamais en base.
2. **`scripts/pack-pub/deposer.mjs <pack_id> <dossier> [--a-sec]`** :
   - usage incorrect → code 2 ;
   - **d'abord** `node scripts/pub-locale-qa.mjs --dossier=<dossier>` : rouge → code 1 avec les critères en échec, **sans aucun accès réseau ni lecture de variable** ;
   - ne dépose que les huit fichiers de `sortie/` (trois films, trois visuels, `textes.md`, `fiche-10-min.md`), jamais `pack.json`, `photos/`, `hf/` ni `manifeste-entrees.json` ; refuse au-delà de 30 Mo ;
   - `--a-sec` : liste les chemins `packs-pubs/<pack_id>/<fichier>` et le poids total, puis sort en code 0, sans réseau ;
   - sinon : charge `.env.local`, mesure l'occupation réelle de tous les buckets comme `promo-heberger.mjs:56-72`, refuse s'il resterait moins de 400 Mo, dépose avec le bon type (`video/mp4`, `image/jpeg`, `text/markdown; charset=utf-8`), puis passe la ligne de `payee` à `fabriquee` par `.eq('etat', 'payee')`, avec `fabrique_le` et `verifications` = le résumé JSON du juge ; si la mise à jour ne touche aucune ligne, le dire et sortir en code 1.
3. **À ne pas faire** : ne pas modifier `site-deposer.mjs` ni `promo-heberger.mjs` ; ne pas afficher de variable d'environnement ; aucune adresse signée ici (c'est la livraison, fiche 15).
