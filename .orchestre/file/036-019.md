# 036-019 — Les systèmes multi-agents dans les gabarits (prompt 6)

## Ce que Benj a dit (03/11, vers 16 h)

- « Vérifie bien qu'il y a bien des agents IA dans les automatisations n8n, que ça respecte bien les vidéos, que c'est bien structuré. »
- « Vérifie aussi qu'il y a bien des systèmes multi-agents dans nos workflows n8n, donc qu'il y a bien des agents dedans qui travaillent. »

Le relevé du 03/11 à 16 h compte 24 agents IA dans 16 gabarits. Chaque agent est un spécialiste qui travaille seul : **aucun agent chef ne
délègue à d'autres agents**. Ce lot comble ce manque.

## À lire, et à citer

1. Les vidéos de l'organigramme d'agents, dans `plans/011-cadrage-01-11/p5-entreprise/fiches-videos-restructureai.md` :
   - A2, un organigramme ;
   - A3, des chefs qui rendent une note structurée ;
   - A14, un agent central.
2. Le prompt, `p6-signature-et-sur-mesure-0311.md` : § 0.3 (l.176-233) et § 2.6, l'organigramme des rangs 1 à 3.
3. Les dépôts sur Oracle (`~/agents/depots/`). Ouvre au moins cinq vrais workflows qui emploient `agentTool` ou des agents en sous-workflow.
   Cherche `@n8n/n8n-nodes-langchain.agentTool` et `toolWorkflow` dans `Zie619_n8n-workflows` et `enescingoz_awesome-n8n-templates`.
4. Le MCP `n8n-oracle` : `get_node_types` sur `@n8n/n8n-nodes-langchain.agentTool` 3 et `agent` 3.1, puis `get_workflow_best_practices`.
5. `plans/011-cadrage-01-11/p6-signature/outillage/OUTILLAGE.md`, en particulier O4 et O5 (R21 à R23).

## À faire

Dans **chaque** gabarit, sur le modèle des vidéos :
- un **agent chef** : AI Agent 3.x, Claude, un seul parseur strict ;
  - il reçoit l'événement, décide quel spécialiste travaille, puis rend une note structurée ;
  - il **ne décide jamais d'un montant** : le code compte ;
- ses **spécialistes en agents-outils** (`agentTool`), chacun avec :
  - sa consigne ;
  - son modèle ;
  - ses outils **de lecture** (R23 s'applique à leurs outils aussi) ;
- une sortie du chef revalidée par un nœud Code (R18), puis la porte « simulation » (R15) devant chaque écriture du chemin principal.

Les spécialistes déjà construits deviennent les agents-outils. Rien n'est perdu.

Rédige `plans/011-cadrage-01-11/p6-signature/outillage/multi-agents.md` : l'organigramme d'agents de chaque gabarit, sous forme de tableau.

## Le juge `scripts/multi-agents-qa.mjs` (hors ligne, mutants obligatoires)

Pour chaque gabarit, il vérifie :
- un chef ;
- au moins deux agents-outils ;
- les spécialistes en lecture seule ;
- le parseur strict du chef ;
- aucun effet sans la porte.

Mutants :
- un gabarit sans chef ;
- un agent-outil qui écrit ;
- un chef sans parseur ;
- un montant pris dans la sortie du chef ;
- un agent-outil sans modèle.

Il doit aussi passer `scripts/n8n-specs-qa.mjs`.
