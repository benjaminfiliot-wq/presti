# CONTRAT.md — ce que `usine-pubs-qa.mjs` exige (fiche 026-199, écrit par Claude Code avant la production de 026-200)

Le cahier de la fiche 026-199 (UP-1 à UP-10, UP-R) dit ce qui est jugé ; il ne dit pas toujours la **forme** des échanges. Ce fichier la fixe, une fois, pour le juge et pour qui écrit la production (026-200) : le juge lit ces formes, les doublures du juge les parlent. Rien ici ne s'ajoute au cahier : chaque ligne en est la lecture la plus simple, et chaque point qui n'y est pas écrit est signalé **[choix du juge]**.

Lancer : `node scripts/usine-pubs-qa.mjs [--racine=<dossier>] [--partie=routes,tourneur,unites] [--temoin] [--preuve-echecs]` ; le tourneur ne tourne que sous Linux (sur le poste, le juge se relance sur l'usine par `scripts/usine.mjs executer`, code 2 si elle est injoignable).

## 1. Les routes (UP-2 à UP-5)

Trois routes, `runtime = 'nodejs'`, `dynamic = 'force-dynamic'`, jeton d'agent `Authorization: Bearer pa_studio_…` (le format de `lib/agents/garde.ts`).

**Gardes (chaque route).** `actif('busAgents')` baissé → 404, **avant** toute identité et sans toucher la base ; sans jeton ou jeton inconnu → 401 ; un agent autre que `studio` (`livreur_usine` compris) → 403 ; `ops_battement` de `studio` à chaque appel authentifié (jamais celui d'un autre agent) ; pause générale **ou** pause de l'agent `studio` : `GET travail` → `{ "travail": null }` (200), `depot` et `rendu` → 423, sans rien écrire ni signer.

**`GET /api/usine/pubs/travail`** — rend l'un de :
- `{ "travail": null }` ;
- `{ "type": "pack", "id": "<uuid>", "pack": <le pack.json de scripts/pack-pub/exporter.mjs pour cette ligne : { pack_id, matiere, site }>, "photos": [{ "nom": "…", "url": "<adresse signée de lecture>" }] }` — sans courriel ni téléphone de l'artisan ou du client ; les photos sont celles de `matiere.photos`, signées dans le bucket `artisan-media`, **600 s au plus**, et **seulement** celles qui sont sous `<artisan_id>/` (une photo qui désigne autre chose n'est jamais signée) ;
- `{ "type": "studio", "decision": "<uuid>", "marque_cle": "…", "page_produit": "<url>", "accord": { "message_id": "…", "recu_le": "<ISO>", "extrait": "…" }, "echantillons_refuses": [<n>…] }` — **exactement ces six clés**, `accord` exactement ces trois ; `extrait` = la phrase d'accord de la réponse de la marque, 400 signes au plus, adresses et numéros masqués ; jamais pour une marque en opposition ou en refus.

Ordre : le plus ancien pack `payee` d'abord (`paye_le`), puis la plus ancienne décision `studio_echantillon` accordée. Un même travail n'est jamais rendu deux fois dans le bail de **90 min** : le pack garde l'état `payee`, le bail est une mise à jour **conditionnelle** (`id` et `etat = payee`) ; à 89 min il est encore sous bail, à 91 min il revient. Un pack qui a échoué **3 fois** (voir `rendu`) n'est plus repris. **[choix du juge]** les compteurs et le bail d'un pack sont dans `packs_pubs.verifications` (`usine_bail_jusqua`, `usine_echecs`, `usine_echec`) ; le juge ne lit que leur effet.

**`POST /api/usine/pubs/depot`** — corps `{ "travail": "<id>", "fichiers": [{ "chemin", "type", "taille" }] }`. Permis seulement :
- pack : `packs-pubs/<pack>/livraison/` + `video-[1-3].mp4` (`video/mp4`) ou `visuel-[1-3].(jpg|png)` (`image/jpeg`, `image/png`), 6 fichiers au plus, **60 Mo** par fichier ;
- Studio : `packs-pubs/studio/<marque_cle>/echantillon-<n>.mp4` (`video/mp4`), **un** fichier, **3 Mo** au plus.
Mo = 1 048 576 octets (comme `deposer-echantillon.mjs`). Tout autre chemin (autre pack, `..`, `//`, majuscules, espaces, doublon), type, taille (non entière, ≤ 0, en texte) ou nombre de fichiers → **400**, aucune adresse. Stockage (`ops_stockage_octets`) au-delà de 60 % ou non mesurable (erreur, valeur nulle) → **507**, aucune adresse. Réponse : `{ "ok": true, "depots": [{ "chemin": "<le chemin demandé, tel quel>", "url": "<adresse signée de dépôt (createSignedUploadUrl)>" }] }`, une adresse par fichier, rien d'autre signé.

**`POST /api/usine/pubs/rendu`** — corps `{ "travail", "ok": true|false, "fichiers": [{ "chemin", "sha256" }], "juge": { "nom", "code", "empreinte_journal" }, "raison"? }`. `ok: true` : la route **relit chaque fichier annoncé** dans le stockage (SHA-256, octets magiques mp4/jpeg/png) et exige le juge (`pub-locale-qa` pour un pack, `pub-qa` pour un échantillon), `code` 0, une empreinte de 64 hexadécimaux ; puis
- pack : six fichiers exactement (3 MP4, 3 visuels), `payee` → `fabriquee` par une écriture conditionnelle (`id` et `etat = payee`), `fabrique_le`, `verifications` ≥ `{ juge: 'pub-locale-qa', verdict: 'PASS' }` (comme `deposer.mjs`) ;
- échantillon : un MP4 sous `studio/<marque_cle>/` ; la décision `studio_echantillon` tranchée en `depose` (par le fondateur), **sauf le premier du Studio** : la route ouvre une décision `regarder_premier_echantillon` (créée par `studio`, options exactement `envoyer` et `refaire`, l'aperçu par un lien signé de **10 min** au plus dans `p_contexte`), répond `ok` sans trancher, et ne tranche `depose` qu'au rendu qui suit son « envoyer ». « Premier » = aucune décision `acq:studio_echantillon:…` de `standardiste` déjà tranchée en `depose`.
Un fichier absent, une empreinte fausse, un juge non vert ou au mauvais nom, un fichier en trop ou en moins → `{ "ok": false, "raison": "<code>" }` (statut 2xx ou 4xx, jamais 5xx) et **rien ne change** hors le compteur d'échecs du pack. `ok: false` annoncé par le tourneur : même effet, même réponse `{ ok: false, raison }`. Au 3e échec (annoncé ou constaté) : plus de reprise automatique (le pack reste `payee`).

**La base que le juge fixe (faux Supabase).** Tables `packs_pubs`, `artisans` ; RPC du bus (`contrat-ops.json`) ; et **deux fonctions que le juge fixe** et que la production doit trouver en base : `acq_studio_a_fabriquer(p_limite integer)` → lignes `{ decision_id, marque_cle, page_produit, accord_message_id, accord_recu_le, accord_texte, opposition, refus, echantillons_refuses }` (les décisions `studio_echantillon` accordées, la plus ancienne accord d'abord) et `acq_studio_bail_poser(p_decision uuid, p_bail_s integer)` → `true` si le bail est posé, `false` s'il court déjà. **[choix du juge — à relire]** ces deux fonctions **n'existent dans aucune migration** à la date du 04/10/2026 (026-200 interdit `supabase/**`) : avant de livrer la route du Studio, soit une migration les définit, soit la fiche 026-200 dit où la route lit autrement ; le juge suit alors cette lecture. Les fonctions du bus : `ops_battement`, `ops_stockage_octets`, `ops_decision_creer`, `ops_decision_trancher`, `ops_decisions_tranchees`.

## 2. Le tourneur (UP-6 à UP-9)

`node --import ./scripts/ts-loader.mjs scripts/usine/pubs.mjs --une-passe [--base=<url>]`, `cwd` = la racine déployée, sous `agents`. Le juge pose `PRESTI_JETON_STUDIO` (jeton tiré au hasard), `PRESTI_URL` et `--base` (la même adresse), `HOME`, `TMPDIR`, `CODEX_LANCEUR` (un faux lanceur exécutable) et un `PATH` qui ne porte que ses doublures (`hyperframes`, `ffmpeg`, `ffprobe`, `elevenlabs`, `veo`, `kling`, `heygen`) et `node`.

**Un pack** : `GET travail` ; photos téléchargées par leurs adresses signées (sans le jeton) dans `~/presti-pubs/<pack>/photos/` ; `pack.json` (les photos désignées par `fichier`, jamais par `url` : `fabriquer.mjs` refuse une adresse) ; si `matiere.voix = 'synthese'`, **avant** la fabrication, `hyperframes tts <texte> --voice=ff_siwis --output=<wav>` sur `texte_voix`, puis `voix.mp3` ; `node scripts/pack-pub/fabriquer.mjs <dossier>` ; `node scripts/pub-locale-qa.mjs --partie=complet --dossier=<dossier>` **vert avant tout dépôt** ; `depot` (les six fichiers de `sortie/`), les envois par les adresses signées, `rendu` (`ok`, empreintes, `juge.empreinte_journal` = SHA-256 de la sortie standard du juge). Juge rouge ou fabrication en échec → aucun `depot`, un `rendu` `ok: false` avec une `raison`. Un verrou par travail (`~/presti-pubs/verrous/<id>.lock`, `wx`, levé à la fin).

**Un échantillon** : le vault `~/presti-studio/<marque_cle>/` (0700) — `prealables.md` copié de `docs/studio/prealables.md` du code déployé, `registre-refus.csv` vide, `marques/<cle>/accord-photos.md` (`Reçu le : JJ/MM/AAAA`, `Message-ID : …`, l'extrait), la page produit `page-produit-AAAA-MM-JJ.html` lue **avec les règles du Lecteur** (`robots.txt` d'abord, `UA_RECENSEUR`, 1 requête par seconde au plus vers l'hôte), `produit.jpg` (l'image principale de la page) ; **`node scripts/studio/garde.mjs --marque=<cle> --vault=<vault>` d'abord** (code 3 → rien d'autre, `rendu` en échec) ; le script par `creerLecteur('studio')` **sur la seule page produit** (le texte de la page : ni script, ni style ; jamais l'accord, l'adresse, le téléphone ni le Message-ID), validé au contrat de `script.json` — `{ marque, produit, lignes: string[], allegations: [{ texte, extrait }], presentateur_virtuel: false }`, chaque `extrait` **exactement** présent sur la page ; `hyperframes tts --voice=ff_siwis` sur les lignes ; `node scripts/studio/monter.mjs <echantillon>` ; `node scripts/pub-qa.mjs <echantillon>` **vert avant tout dépôt** ; `depot` (un MP4), envoi, `rendu` (juge `pub-qa`). Aucun outil payant, aucun script de repli du poste (`exporter.mjs`, `deposer.mjs`, `deposer-echantillon.mjs`).

**Secrets et données (UP-8).** Le jeton n'apparaît dans aucun argv, aucune sortie, aucun journal, **aucune variable d'environnement d'un outil enfant**, et n'est envoyé qu'à Presti (jamais au stockage ni à la marque) ; la sortie ne porte que des identifiants et des comptes (jamais une adresse, un numéro, un texte de réponse ni un Message-ID) ; rien n'est écrit hors de `~/presti-pubs/`, `~/presti-studio/` et du dossier temporaire (`TMPDIR`), **vide à la fin du passage**, ni dans la racine déployée.

**Pannes (UP-9).** Bus ou stockage injoignable, bus en 500 : une ligne de journal, code 0, aucune exception, le travail repris au passage suivant (le verrou est levé même en échec). `hyperframes` absent : `rendu` en échec dont la `raison` contient `outil_absent`, jamais un faux vert.

**Doublures du juge.** `fabriquer.mjs`, `pub-locale-qa.mjs`, `pub-qa.mjs`, `monter.mjs`, `deposer*.mjs`, `exporter.mjs` sont remplacés dans la racine déployée d'essai par des doublures qui consignent leurs arguments (`journal.jsonl`, heure monotone) ; `garde.mjs` est une doublure qui lance le **vrai** garde du dépôt (son code 3 est celui du dépôt) ; le faux lanceur de Codex consigne tout ce qu'il reçoit. Les faux serveurs consignent chaque requête. Le juge ne croit aucun journal du code jugé.

## 3. Les unités (UP-10)

`presti-pubs.service` : `User=agents`, `WorkingDirectory=/srv/presti-agents`, `Environment=CODEX_LANCEUR=/usr/local/bin/presti-ia-modele`, aucun `EnvironmentFile=`, `MemoryMax` ≤ 4G, `Nice=10`, `ExecStart=/usr/bin/node scripts/usine/avec-coffre.mjs PRESTI_JETON_STUDIO -- /usr/bin/node --import ./scripts/ts-loader.mjs scripts/usine/pubs.mjs --une-passe` (`PRESTI_JETON_LIVREUR_USINE` n'y figure pas). `presti-pubs.timer` : toutes les 15 min, `Persistent=true`, `[Install] WantedBy=timers.target`. La liste fermée de `scripts/usine/coffre-regles.mjs` doit porter `PRESTI_JETON_STUDIO` (sinon `avec-coffre.mjs` refuse : code 2).

## 4. Le témoin et les sabotages

`temoin/` est UNE forme conforme (routes, `lib/pubs/usinePubs.ts`, tourneur, unités), posée ici pour prouver que le juge **passe sur une référence juste** et **échoue sur chaque faute plantée** : `--preuve-echecs` joue le témoin puis ses sabotages (la table `SABOTAGES` de `preuve-echecs.mjs` : une faute par copie du témoin — le jeton de `livreur_usine` accepté, une empreinte non vérifiée, un juge ignoré, le jeton dans le journal… —, le compte est celui de la sortie), chacun doit mettre son critère au rouge. Le témoin n'est jamais déployé et ne s'importe nulle part ailleurs.
