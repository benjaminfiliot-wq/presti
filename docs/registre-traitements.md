# Registre des traitements — l'entreprise Presti

> Côté ARTISAN, le registre est dans `lib/legalArtisan.ts` (ce que Presti traite pour le compte de chaque artisan : ses prospects, ses devis, ses factures). Ce fichier-ci est le registre de **l'entreprise Presti** en tant que responsable de traitement : ses clients (les artisans), ses fondateurs, ses fournisseurs. Une ligne par traitement, complétée à chaque jalon du prompt v10.

| Traitement | Finalité | Données | Base légale | Personnes | Durée | Destinataires / sous-traitants | Où dans le code |
|---|---|---|---|---|---|---|---|
| **Centre de direction — journal** (J1, 07/09/2026) | Traçabilité des actions des fondateurs sur l'entreprise (accès, argent, données d'artisan) : qui, quoi, quand, avant/après | Identifiant et email du fondateur, action, cible, état avant/après (minimal, sans secret ni contenu de prospect), **adresse IP en clair**, navigateur | Intérêt légitime (sécurité, preuve, obligations comptables) | Fondateurs (Benjamin, Alexandre) | **24 mois** (trigger d'immuabilité, purge `lib/purgesRgpd.ts`) | Supabase (hébergement, UE) | `supabase/migrations/0065_direction.sql`, `lib/direction/journal.ts` |
| **Centre de direction — re-confirmation** (J1) | Vérifier le mot de passe avant une action sensible | Empreinte sha256 d'un jeton court, identifiant, portée, dates | Intérêt légitime (sécurité) | Fondateurs | 5 min de validité ; lignes expirées purgées après 7 j | Supabase | `lib/direction/reconfirmation.ts` |
| **Centre de direction — alertes** (J1) | Garder les alertes internes (budget IA, paiements, crons, sécurité) jusqu'à acquittement | Motif, sujet, corps technique (jamais une donnée de prospect), qui a acquitté | Intérêt légitime (continuité de service) | Fondateurs | Acquittées : 12 mois | Supabase, Resend (l'email d'alerte) | `lib/alertes.ts`, `app/api/direction/alertes` |
| **Centre de direction — lectures** (J1) | Piloter l'entreprise : état du service, chiffres (MRR, encaissé, essais), file des actions | Agrégats Stripe (montants, statuts d'abonnement, nom du client Stripe), comptes d'artisans (offre, crédits, date d'inscription, nom, métier) — **jamais** le contenu des conversations, devis ou factures des artisans, ni leurs prospects | Intérêt légitime (gestion) / contrat avec l'artisan | Artisans clients (agrégés), fondateurs | Pas de stockage propre (lectures à la source, cache 60 s en mémoire) | Stripe, Supabase, Resend, Anthropic (coûts, si clé Admin) | `lib/direction/stripe.ts`, `app/api/direction/*` |
| Messagerie de l'entreprise (J3) | *à compléter au J3* | | | | | | |
| Mode support « voir comme lui » (J5) | *à compléter au J5 — journalisé et notifié à l'artisan* | | | | | | |

**Droits** : les fondateurs sont les seules personnes concernées par le journal ; l'IP y est une preuve d'action, non anonymisée, conservée 24 mois puis effacée. Les artisans n'y figurent que par leur identifiant technique quand une action les concerne (changement d'offre, crédits…), et peuvent en obtenir l'extrait par l'export de leurs données.
