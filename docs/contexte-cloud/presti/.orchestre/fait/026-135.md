## Contexte

Presti vend un pack pubs locales à 149 € : trois vidéos verticales de 15 s, trois visuels carrés, les textes d'annonce et une fiche « lancer la pub en 10 minutes », faits **seulement** avec les photos de l'artisan. Avant de payer, l'artisan remplit un dossier. Le code d'argent existe déjà (fiches 03 et 04) :
- `lib/packPub.ts` : le contrat (`ACCROCHES_PACK`, `erreursAvantPaiementPack`, états) ;
- `lib/packPubServeur.ts` : `brouillonPackDe(uid)` et `enregistrerBrouillonPack(uid, email, dossier)`, seuls à écrire dans la table `packs_pubs`.

Le modèle de route est le dossier du site, `app/api/site/commander/brouillon/route.ts` (GET et PUT, drapeau `siteCommande`, `authArtisan`).

**Le risque à fermer.** Les photos d'un artisan sont dans le bucket **public** `artisan-media`, au chemin `<uid>/<horodatage>-<aléa>.<ext>` (`app/api/media/route.ts:96`, adresse publique `:122`). Un dossier qui accepterait n'importe quelle adresse ferait fabriquer une pub avec les photos d'un autre artisan, ou avec une image prise n'importe où. Le type de fichier y est déduit de `?ext=` sans contrôle des octets (`:67-68`) : ce contrôle est fait plus tard, au décodage, par la fabrication (fiche 12).

Contrat du dossier (`matiere`) :
- `photos` : 6 à 12 éléments `{ url, role: avant|apres|chantier|detail|equipe, paire?: texte ≤ 20, personnes: booléen, accord_personnes: booléen }` ; `personnes = true` exige `accord_personnes = true` ; `role = equipe` exige `personnes = true` ;
- `logo_url` : texte ou nul, même règle d'adresse que les photos ;
- `faits` : `metier` (1-40), `ville` (1-60), `communes` (0 à 5, chacune ≤ 60), `duree_travaux?` (≤ 40), `materiaux?` (≤ 60), `decennale` (booléen), `cta` (`devis|appel|message`), `telephone?` (exigé si `cta = appel`, format français) ;
- `accroche` : une valeur de `ACCROCHES_PACK` ;
- `voix` : `aucune|synthese` ; `texte_voix` (20 à 220 signes, **aucun chiffre** : nombres en lettres) exigé si `synthese` ;
- `consentement_droits` : `true`.

Compatibilité Next 16 : pas d'accès synchrone à `params`, pas de middleware.

Dépend de : 026-110 PASS (juge), 03 PASS (noyau). La table de la fiche 02 sert à l'exécution, pas au juge.

## Ce qu'il faut faire

1. **`lib/packPubDossier.ts`**, sans réseau ni base :
   - `nettoyerDossierPack(entree: unknown, contexte: { uid, urlSupabase, photosDuSite: string[], decennaleDeclaree: boolean })` → `{ ok: true, dossier } | { ok: false, erreurs: { champ, message }[] }` ;
   - n'accepte une adresse de photo ou de logo que si elle commence par `<urlSupabase>/storage/v1/object/public/artisan-media/<uid>/`, ou si elle figure telle quelle dans `photosDuSite` ;
   - retire tout champ hors contrat ; borne chaque texte ; ôte les balises ; refuse un chiffre dans `texte_voix` ;
   - force `faits.decennale` à `false` quand `decennaleDeclaree` est faux (la décennale ne se déclare que dans le dossier du site, avec assureur et numéro) ;
   - applique les règles `personnes` / `accord_personnes` / `equipe`.
2. **`app/api/pubs/commander/brouillon/route.ts`** :
   - `GET` et `PUT` ; première instruction de chacun : `if (!actif('packPub')) return new NextResponse(null, { status: 404 })` ; puis `authArtisan` ;
   - `GET` rend `{ brouillon, photosDuSite, decennaleDeclaree }` : le brouillon par `brouillonPackDe`, les photos et la décennale de la **dernière** commande de site de cet artisan (`sites_commandes`, `.eq('artisan_id', uid)`, par `supabaseAdmin`) ;
   - `PUT` relit ce même contexte côté serveur (jamais celui envoyé par le navigateur), appelle `nettoyerDossierPack`, rend 400 avec les erreurs, sinon `enregistrerBrouillonPack` et rend le brouillon ;
   - la route n'écrit jamais elle-même dans `packs_pubs`.
3. **À ne pas faire** : ne pas toucher `/api/media` ni `lib/media.ts` ; ne rien télécharger ; aucune donnée réelle dans les commentaires.
