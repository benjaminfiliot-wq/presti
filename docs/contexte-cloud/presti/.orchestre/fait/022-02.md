# 022-02 — La série 2 des publications Presti (n° 11 à 16)

## Contexte

Les dix publications de la série 1 sont toutes parues le 14/09 (voir `plans/journal-publications.md`). Leur source est
`plans/publications-10.md`. Chaque publication y contient :
- le mécanisme réel ;
- deux variantes ;
- le premier commentaire et trois réponses type ;
- un sourçage ligne à ligne dans le code ;
- ce qui n'est **pas** dit, et pourquoi.

C'est ce niveau de preuve qui a fait passer la série 1. Le 10/09, une version sans sourçage affirmait des choses fausses
dans sept publications sur dix.

Il faut la série 2, au même format, sur des sujets que la série 1 n'a pas traités.

**Canaux :**
- variante **A** : la **Page Facebook « Presti »** (la Page, pas le profil personnel de Benjamin) ;
- variante **B** : **Instagram @prestiapp**.

Pas de LinkedIn : ce réseau est tenu par Louis-Victor.

## Ce qu'il faut faire

1. Lis en entier :
   - `plans/publications-10.md` : le format, le ton, les règles ;
   - `plans/publications-lancement.md` §0 : ce qu'on a le droit de dire ;
   - `plans/accroches-par-metier.md` : dire « mon logiciel », jamais « mon IA » ;
   - les pièges de `SaaS/Prospection/Guide-Presti-Demarchage.md`.
2. Pars des six sujets ci-dessous et **vérifie chacun dans le code avant d'écrire**. Si un sujet ne se vérifie pas,
   remplace-le par un autre qui se vérifie, et explique-le dans « Ce qui n'est PAS ».
   - **11 · les comptes clients** : le client de l'artisan retrouve ses échanges et ses devis par un lien, sans mot de
     passe. Point de départ : `lib/clientAuth.ts`, `app/api/p/auth`, `lib/plans.ts`.
   - **12 · la facture électronique Factur-X**. Point de départ : `facturx`, `lib/plans.ts`.
   - **13 · l'application sur le téléphone** : photo du chantier, lecture d'un code-barres, déverrouillage biométrique.
     Point de départ : `lib/natif.ts`, `app/confidentialite/page.tsx` §9.
   - **14 · les données de l'artisan cloisonnées et la double authentification**. Point de départ : les politiques RLS de
     `supabase/migrations`, `lib/authArtisan.ts`, `mfa`.
   - **15 · la demande reçue à 23 h** : l'accusé de réception au nom de l'artisan part tout de suite, la vraie réponse
     attend son accord en Essentiel. Point de départ : `lib/plateformeConfig.ts`, `lib/aide.ts`.
   - **16 · les photos avant/après et le portfolio sur la vitrine**. Point de départ : `app/AvantApresUpload.tsx`,
     `app/PortfolioUpload.tsx`, `lib/plans.ts`.
3. Écris `plans/publications-serie-2.md`, avec une section par publication, dans exactement cet ordre de titres :
   - `# Publication n° 11 — « Titre »`
   - `## Le mécanisme réel qui la fonde`
   - `## Variante A — Facebook`
   - `## Variante B — Instagram`
   - `## Le premier commentaire (à poster soi-même, dans la minute)`
   - `## Trois réponses type`
   - `## Sourçage ligne à ligne`
   - `## Ce qui n'est PAS dans cette publication, et pourquoi`
4. Chaque variante :
   - fait entre 200 et 2 200 caractères, et vouvoie les artisans ;
   - porte le lien tracké de son canal : `prestiapp.fr/a/facebook` pour A, `prestiapp.fr/a/instagram` pour B.

   La variante B contient en plus une ligne `Visuel : <chemin>`, vers un fichier qui **existe** dans le dépôt et qui
   montre le sujet. Par exemple une image de `publications/pub-XX/planches-vertical/`, un
   `publications/pub-XX/vertical-miniature.jpg` ou une image de `public/demo/`. Si aucun fichier ne montre le sujet,
   prends l'image la plus proche et dis-le dans « Ce qui n'est PAS ».
5. **Sourçage** : au moins cinq renvois `chemin:ligne` par publication, dans un tableau
   « Ce que la publication affirme | Où c'est vrai dans le code », comme dans la série 1. La ligne citée doit contenir ce
   qu'elle prouve.
6. **Interdits** (le juge les refuse) :
   - « Preti » (le produit s'appelle Presti) ;
   - des heures gagnées ;
   - « rien ne part sans vous » ;
   - des tarifs fournisseurs mis à jour automatiquement ;
   - WhatsApp ;
   - la lecture de factures fournisseurs ;
   - le site à 300 € ou « site à la demande » ;
   - des témoignages ou un nombre de clients ;
   - « mon IA » ;
   - des relances « automatiques » sans la réserve Studio (59 €).
7. Ne lance aucun script : ton bac à sable ne peut pas lancer de sous-processus. Le vérificateur tourne hors bac à sable.

- Rien n'a bougé hors de `plans/publications-serie-2.md`.
