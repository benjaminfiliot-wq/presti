# 021-09 — le film comparatif natif / Lenis

**Pourquoi.** Benj a demandé des « smooth animations » pour la démo Atelier Lestraque
(https://prestiapp.fr/sites-demo/lestraque/index.html). Les sites de MotionSites lissent souvent le défilement avec Lenis.
Mais Lenis change la sensation de toute la page, et c'est Benj qui tranchera (question Q-B du cahier de la vague 5). Il lui
faut deux films identiques, l'un natif, l'autre avec Lenis, montés côte à côte. Rien ne change dans le site.

**Références** (lecture seule) : `.orchestre/preuves/021-00/ref-recit.md` §3.2 pour les réglages de Lenis, et
`scripts/demo-video.mjs` pour la méthode des flashs blancs qui recale l'horloge de la vidéo Playwright.

**Ce qu'il faut faire.**
1. **La démo en local** : copie `public/sites-demo/lestraque/` dans `.orchestre/travail/021-09/site/`, puis sers cette copie
   par un petit serveur http local. Le dossier est autonome : styles.css, site.js, fonts, images.
2. **Lenis sans toucher au projet** :
   - `npm pack lenis@1.3.26` dans `.orchestre/travail/021-09/` (aucun `npm install` dans le projet, aucun CDN) ;
   - recopie le fichier minifié du paquet, avec son en-tête de licence MIT, dans `.orchestre/preuves/021-09/lenis.min.js`.
3. `tournage.mjs` (Playwright, Chromium, 1440 × 900, `deviceScaleFactor` 1, carte graphique permise
   `--use-gl=angle --enable-webgl --ignore-gpu-blocklist`) :
   - **natif** : la page telle quelle ;
   - **lenis** : le même tournage, avec Lenis injecté par `page.addInitScript` et les réglages
     `{ lerp: 0.1, smoothWheel: true, syncTouch: false }` ;
   - **molette réelle** (`page.mouse.wheel`), selon un **programme fixe** d'au moins 5 événements `{t, dy}`, identique pour
     les deux films ;
   - 12 s par film, vidéo Playwright recalée sur deux flashs blancs comme `demo-video.mjs`, sortie H.264 1440 × 900 à
     30 images/s → `natif.mp4`, `lenis.mp4` ;
   - relève pour chaque film le temps entre le dernier événement de molette et l'arrêt de `scrollY` (`arretMs`), et le p95
     des intervalles entre deux `requestAnimationFrame` (`rafP95Ms`).
4. `cote-a-cote.mp4` : ffmpeg `hstack`, natif à gauche, Lenis à droite, sur la même horloge (2880 × 900, ou réduit en gardant
   le rapport 3,2).
5. `planche.jpg` : 4 instants, natif au-dessus de Lenis.
6. `mesures.json` :
   ```json
   { "version": "1.3.26", "reglages": { "lerp": 0.1, "smoothWheel": true, "syncTouch": false },
     "programme": [ { "t": 1.0, "dy": 300 } ],
     "natif": { "programme": [ … le même … ], "arretMs": 0, "rafP95Ms": 0 },
     "lenis": { "programme": [ … le même … ], "arretMs": 0, "rafP95Ms": 0 } }
   ```
   Les valeurs de l'exemple ne sont qu'une forme. Écris les valeurs mesurées.

**Règles.** Rien dans `public/`, `scripts/`, `package.json` ni `node_modules/`, et aucune commande git.

**Fini quand** `verifier` passe. Il contrôle les formats et la même horloge des deux moitiés du montage, compare les images, et
vérifie que la page défile, que le programme est identique, que Lenis agit bien et que le site n'a pas bougé.
