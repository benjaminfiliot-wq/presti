## Contexte

La production des sites payés passe sur l'usine Oracle `presti-usine` (rectification du 24/09 §3.12, décision R11, provisoire). L'usine n'a **jamais** la clé de service Supabase. Ses agents ont un jeton d'agent (026-040), limité à leurs types et à leurs tables, et déposent leurs fichiers par des URL signées que rend une route de Vercel (fiche 06). Il faut pour cela, dans la base :

1. **Un bucket privé `usine`**, séparé des buckets servis (`sites`, `maquettes`) : ce que l'usine dépose n'est jamais servi tel quel ; le serveur le relit, le décode et le copie ailleurs. Limites : 8 Mo par fichier, et les seuls types du contrat de l'usine (la livraison d'un site) : `text/html`, `text/css`, `text/javascript`, `application/javascript`, `application/json`, `image/webp`, `image/avif`, `image/jpeg`, `image/png`, `image/svg+xml`, `font/woff2`, `text/plain`, `application/xml`, `text/xml`. Les maquettes n'y passent pas : l'atelier de l'usine dépose dans le bucket `maquettes` par ses propres routes (026-097 réécrite). Aucune politique sur `storage.objects` : seul `service_role` lit et écrit, comme le bucket `sites` (`0089_sites_bucket.sql:23-28`).
2. **`public.ops_tache_detenue(p_agent text, p_id uuid)`** : la route de dépôt doit savoir qu'un agent tient **vraiment** une tâche sous bail avant de signer quoi que ce soit. `ops.taches` est fermée (0096) : on passe par une fonction. Elle rend `table(id uuid, type text, cle_idempotence text, capacite text, charge jsonb, bail_jusqua timestamptz)`, **seulement** si `id = p_id and agent = p_agent and statut = 'bail' and bail_jusqua > now()`, zéro ligne sinon. Lecture seule, sans événement.
3. **Les graines** des deux agents de l'usine, par `select public.ops_agent_enregistrer(p_nom, p_libelle, p_capacites, p_types_crees, p_tables, p_periode_minutes, p_debit_minute, p_quota_creations_jour, p_plafond_euros_jour)` (0097 : insère ou met à jour, sans toucher au jeton, au battement ni à la pause ; la migration se rejoue sans dommage) :

   | nom | libellé | capacités | types créés | tables | période (min) | débit/min | quota/jour | plafond €/jour |
   |---|---|---|---|---|---|---|---|---|
   | `usine` | Surveillance de l'usine | `{surveillance}` | `{}` | `{evenements,decisions}` | 30 | 30 | 2 | 0 |
   | `livreur_usine` | Livreur de sites (usine) | `{livraison}` | `{}` | `{taches,evenements}` | 60 | 30 | 0 | 0 |

   - La surveillance bat toutes les 15 min : 30 min de période, le veilleur (026-047) crie « usine injoignable » au-delà d'une heure. Ses 2 créations par jour sont la décision hebdomadaire de seuil et sa marge.
   - Le livreur de l'usine bat à chaque passage de son minuteur (toutes les 10 min) : 60 min de période.
   - `livreur_usine` a la capacité `livraison` : le coupe-circuit du veilleur ne le met jamais en pause (026-047), et il prend les tâches `livrer_site` que `systeme` crée pour chaque commande payée (026-046). `usine` a la capacité `surveillance`, elle aussi exemptée du coupe-circuit.
   - `livreur_usine` est distinct de `livreur` (graine de 0105, qui bat depuis le tic de Vercel) : deux processus qui battraient pour le même agent masqueraient la panne de l'un. Cette migration ne touche ni `atelier_maquettes`, ni `livreur`, ni `chef` : leurs graines, et leurs périodes, sont celles de 0105 (026-060).

La connexion directe à la base est refusée depuis le 14/09 : l'essai à sec passe par l'outil `execute_sql` du connecteur Supabase, en **un seul** énoncé `do … raise exception`, qui annule tout (mémoire `essai-a-sec-migration`). Le bloc se génère avec `blocEssai` de `scripts/lib/sql-essai.mjs` (026-009), jamais retapé à la main.

## Ce qu'il faut faire

1. **`supabase/migrations/0110_usine_socle.sql`**, avec un en-tête qui dit pourquoi (même style que 0088 et 0089 : l'usine, sa règle « jamais la clé de service », son numéro 0110, fixé à l'assemblage) :
   - le bucket : `insert into storage.buckets (id, name, public, file_size_limit, allowed_mime_types) values ('usine', 'usine', false, 8388608, array[…les quatorze types…]) on conflict (id) do update set public = false, file_size_limit = 8388608, allowed_mime_types = excluded.allowed_mime_types;` ; aucune politique ;
   - `create or replace function public.ops_tache_detenue(p_agent text, p_id uuid) returns table (…) language sql stable security definer set search_path = pg_catalog, ops as $$ … $$;` avec exactement le filtre du contexte ; `revoke all on function public.ops_tache_detenue(text, uuid) from public, anon, authenticated;` ; `grant execute on function public.ops_tache_detenue(text, uuid) to service_role;` ;
   - les deux `select public.ops_agent_enregistrer(…)` du tableau, argument par argument.
2. **Les jumeaux** : `node scripts/sql-nu.mjs supabase/migrations/0110_usine_socle.sql supabase/migrations/_A_COLLER_sql_editor_0110_NU.sql`, et `_A_COLLER_sql_editor_0110.sql` = la migration complète avec son pied de contrôle (`MARQUE_CONTROLE`).
3. **Le contrôle** `supabase/controles/0110_usine_socle.sql` : lecture seule ; une ligne « oui » ou « non » pour le bucket privé, sa limite et ses types, la fonction (`security definer`, droits : `service_role` seul), et chacun des deux agents avec sa période.
4. **L'essai à sec**, par `execute_sql` sur le projet de Presti, avec le bloc rendu par `blocEssai` : il exécute le jumeau nu ; enregistre un agent `essai_e2e_<aléa>` de capacité `livraison` (type créé `livrer_site`) ; crée une tâche d'essai, la fait prendre par cet agent (`ops_tache_prendre`), puis vérifie que `ops_tache_detenue` la rend pour lui et **ne la rend pas** pour `livreur_usine` ni pour un id inventé ; tente `ops_tache_detenue` sous `set local role anon` puis `authenticated` (refusé) ; lit le bucket et les deux agents ; puis lève `ESSAI_A_SEC <empreinte> <json>`. Ensuite, `to_regprocedure('public.ops_tache_detenue(text,uuid)')` doit valoir `null` et le bucket `usine` ne doit pas exister : écrire `APRES rien_ne_reste=true`. Le compte rendu complet va dans `essai-a-sec.txt`. Dire à Benj qu'un essai à sec a tourné sur la production.
5. **À ne pas faire** : ne pas l'appliquer pendant la fiche (Claude Code l'applique après le PASS, par le connecteur) ; ne pas toucher aux migrations existantes ; aucune donnée réelle dans l'essai ; aucune politique sur `storage.objects`.
