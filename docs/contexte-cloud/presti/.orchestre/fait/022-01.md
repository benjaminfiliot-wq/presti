# 022-01 — Trente artisans à contacter sur Instagram

## Contexte

Presti démarche des artisans du bâtiment par message privé depuis le compte Instagram @prestiapp. 32 artisans de
Charente-Maritime ont déjà été contactés entre le 09 et le 14/09. Ces comptes, la réserve et les comptes écartés sont
listés dans `SaaS/Prospection/deja-contactes-instagram.txt`. Il faut le lot suivant : trente comptes Instagram
d'artisans ou d'entreprises du bâtiment, réels et actifs, qui publient leurs chantiers.

Claude Code vérifiera chaque compte dans le navigateur connecté de Benj avant tout message. Un compte inventé serait
découvert, et la tâche refusée.

## Ce qu'il faut faire

1. Cherche avec ton navigateur **sans te connecter à Instagram**. Pas de création de compte, pas d'abonnement, pas de
   message, pas de « j'aime » : tu lis, rien d'autre. Sources utiles :
   - des recherches web du type `site:instagram.com plombier Royan` ou `site:instagram.com carreleur "Niort"` ;
   - les fiches PagesJaunes et les sites d'artisans qui renvoient vers leur Instagram ;
   - la page publique `instagram.com/<compte>/` quand elle s'affiche.
2. Zones, dans cet ordre :
   - **Charente-Maritime (17)** : Royan, Saintes, Rochefort, Marennes, Surgères, Saint-Jean-d'Angoulême, île de Ré,
     Oléron ;
   - **Vendée (85)** : La Roche-sur-Yon, Les Sables-d'Olonne, Luçon, Fontenay-le-Comte ;
   - **Deux-Sèvres (79)** : Niort, Bressuire ;
   - **Charente (16)** : Angoulême, Cognac.
3. Ne garde un compte que s'il remplit les trois conditions :
   - c'est un artisan ou une entreprise du bâtiment. Pas un particulier, un magasin, un fabricant ou une plateforme de
     mise en relation ;
   - il montre des chantiers ;
   - il n'est pas dans `SaaS/Prospection/deja-contactes-instagram.txt`, ni par identifiant, ni par nom affiché (les
     lignes « nom: »).
4. Écris `SaaS/Prospection/cibles-instagram-2026-09-15.json` sur ce modèle :

```json
{
  "genere_le": "2026-09-15T15:00:00Z",
  "methode": "comment tu as cherché, en une ou deux phrases",
  "cibles": [
    {
      "handle": "identifiant_exact_sans_arobase",
      "nom_affiche": "le nom affiché du compte",
      "metier": "Plombier",
      "ville": "Royan",
      "departement": "17",
      "bio_extrait": "texte vu tel quel : la bio, ou l'extrait du résultat de recherche",
      "source_url": "https://… la page où tu l'as vu",
      "pourquoi": "une phrase : pourquoi c'est un vrai artisan qui correspond"
    }
  ]
}
```

   Règles pour ce fichier :
   - `metier` reprend **exactement** un libellé de la première colonne du tableau de `plans/accroches-par-metier.md`
     (par exemple « Plombier », « Plaquiste / Plâtrier », « Multiservices / Rénovation », « Couvreur ») ;
   - au moins six métiers différents, et sept comptes au plus pour un même métier ;
   - **n'invente rien** : si tu n'as pas vu une information, ne garde pas le compte.
5. Écris tes requêtes de recherche dans `.orchestre/preuves/022-01/recherches.md`, une par ligne.

## C'est fini quand

- `node scripts/cibles-instagram-qa.mjs` est vert, avec au moins 25 cibles valides.
- `.orchestre/preuves/022-01/recherches.md` existe et n'est pas vide.
- Rien n'a bougé hors du périmètre.
