## Contexte

Un pack pubs livré reste dans le bucket privé `packs-pubs`, sous `packs-pubs/<id>/` (trois films, trois visuels, deux textes, 30 Mo au plus), le temps que l'artisan le télécharge : ses liens durent 30 jours (`lien_expire_le` dans la table `packs_pubs`, posé à la livraison, fiche 15). L'article 3 ter des CGU promet ensuite l'effacement (fiche 05). Et le stockage Supabase fait **1 Go partagé avec les photos de tous les artisans** : un dépassement coupe tout le monde (`scripts/promo-heberger.mjs:23`, marge de 400 Mo).

La table porte `fichiers_effaces_le` (nul tant que rien n'est effacé ; migration 0102, fiche 02).

**Où l'appeler.** Vercel Hobby n'a que deux tâches planifiées : la purge vit donc dans la tâche quotidienne des relances, comme les autres purges (`app/api/cron/relances/route.ts:128-146` : `purgerComptes`, cache des prix, puis `purgerRgpd` dans un `try` suivi de `enregistrerPassage('purges-rgpd', …)`). Ce bloc tourne **PC éteint**, sur Vercel. La fiche 026-024 modifie aussi cette route : l'orchestre sérialise les deux fiches, et le juge compare le diff à `HEAD`.

Outils : `supabaseAdmin.storage.from('packs-pubs').list(prefixe)` et `.remove([chemins])` ; `enregistrerPassage(nom, detail, reussi)` (`lib/alertes.ts:201`), qui laisse la ronde voir une purge muette.

Dépend de : 026-110 PASS (juge), 02 PASS (colonne), 15 PASS (livraison).

## Ce qu'il faut faire

1. **`lib/packPubPurge.ts`** :
   - `packsAPurger(lignes, maintenant)`, pure : garde seulement les lignes `etat = 'livree'` dont `lien_expire_le` est passé et `fichiers_effaces_le` est nul ; les plus anciennes d'abord ; 20 au plus ;
   - `purgerPacksExpires(maintenant = new Date())` → `{ effaces: number, fichiers: number, erreurs: string[] }` : lit les candidats (colonnes utiles seulement), applique `packsAPurger`, liste puis retire les fichiers de chaque pack, puis pose `fichiers_effaces_le` par une mise à jour conditionnée `.is('fichiers_effaces_le', null)` ; toute erreur est ajoutée à `erreurs`, **jamais levée** (une purge qui échoue ne doit pas empêcher les relances de partir).
2. **`app/api/cron/relances/route.ts`** : un import et un seul bloc, juste après celui des purges RGPD :
   `try { const r = await purgerPacksExpires(); await enregistrerPassage('purge-packs', r, r.erreurs.length === 0) } catch (e) { await enregistrerPassage('purge-packs', { erreur: … }, false) }`. Rien d'autre ne change dans ce fichier ; le résultat peut s'ajouter à la réponse JSON de la route.
3. **À ne pas faire** : ne jamais effacer un pack `payee` ou `fabriquee` (Benj ne l'a pas encore regardé, ou l'artisan ne l'a pas reçu) ; ne pas toucher aux autres purges ; aucune tâche Vercel de plus.
