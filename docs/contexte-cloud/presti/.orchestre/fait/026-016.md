## Contexte

Série 026, domaine **acquisition**. Les agents : A7 (vigie Meta), A8 (recenseur), J1 (juge des faits), A1 (la Plume, rédacteur), J3 (conformité et promesse) et le second juge, le **Facteur** (seul agent qui fait partir un message), A3 (le Standard, qui lit et classe), le **Répondeur** (qui répond dans le fil, annoncé comme IA), A2 (l'Atelier : maquette et vidéo, sur l'usine Oracle).

**Décision de Benj du 24/09 au soir** (rectification §3.1) : les agents trouvent, vérifient, écrivent, envoient, relancent, répondent et qualifient. Benj ne reçoit que les appels réservés et les paiements, plus les cartes Attention. Plus aucun lot à copier, plus aucune réponse à relayer, plus aucun envoi à la main. Chaque message part par le seul Facteur, avec **trois verdicts enregistrés** (J1 : faits ; J3 : conformité, déterministe ; second juge : ton et promesses implicites). Le message privé Instagram envoyé à froid est écarté (décision R5) : Instagram devient un canal **entrant** (commentaires « SITE », messages reçus). Depuis la voie gratuite du 25/09, le premier contact passe par le **formulaire de contact du site** de l'entreprise, un par entreprise et à vie, par paliers de 5 à 40 par jour, au plus tôt le 12/10/2026 ; aucune adresse n'est relevée sur un site ; la suite de la conversation part du Gmail de prospection, seulement à qui a écrit. Jamais `prestiapp.fr` avant un « oui ».

Règle 1 de `CLAUDE.md:23` : Claude Code écrit les juges, jamais l'exécutant qui les utilise. Aucune fiche d'acquisition de Codex ou d'Antigravity ne se dépose dans `file/` avant le PASS du juge qui la juge.

**Le parti pris de conception, que fixe ce contrat :** chaque agent est une bibliothèque **pure** sous `lib/agents/acquisition/`, qui reçoit tout ce qui touche le monde par injection : le réseau (`Recuperateur`), le temps (`Horloge`), la base (`Magasin`), le modèle (`Lecteur`), le stockage (`Stockage`), les porteurs d'envoi (`Porteur`, définis par 026-089 dans `porteurs.ts`, pas ici). Les routes ne font que brancher le réel. Ainsi chaque juge tourne hors ligne, sur des jeux d'essai, sans la base de production ni le réseau, et le même code tourne ensuite sur Vercel (PC éteint) ou sur l'usine.
