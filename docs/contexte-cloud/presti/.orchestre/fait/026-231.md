## Contexte

026-230 dépose deux archives dans `/srv/presti-savoir/depot/` (`agents:agents`, 2770, créé par `gardien` à la mise en service, 026-241). Ici, tout se passe **sous le compte `agents`**, qui n'a ni sudo ni shell (docs/agents/usine.md) : une unité `.path` voit le fichier `.pret`, un service valide l'archive et la pose dans le seul endroit où `agents` écrit, `/home/agents/travail/` (700). Le compte `usine`, qui fait tourner Codex avec le réseau pour l'orchestre, ne lit rien sous `/home/agents` : le compartiment `prospects` n'est lisible que par les scripts des agents, qui ne le passent qu'à Codex (file IA, `personnelles: true`) ou à du code sans modèle (026-233).

Les unités portent le préfixe `presti-chef-` : elles entrent dans le groupe `chef` de `scripts/usine-agents.mjs` (motifs `presti-chef*`, minuteurs et chemins activés par `installer chef`) sans rien changer au socle de 026-050, dont le juge exige exactement deux règles sudoers.

Le sémantique est facultatif : des vecteurs calculés par l'Ollama de l'usine (`127.0.0.1:11434`), jamais ailleurs, pour `general` seulement, et seulement si `semantique` est allumé dans `docs/savoir/reglages.json` avec un modèle choisi (aucun n'est installé : un troisième modèle attend le « oui » de Benj). Éteint, l'index est plein texte, et c'est suffisant pour démarrer.

## Ce qu'il faut faire

1. **`scripts/usine/savoir-recevoir.mjs --depot=<dossier> [--racine-travail=/home/agents/travail/savoir]`** (Node pur, sans processus enfant) :
   - pour chaque `<nom>.pret` du dépôt, du plus ancien au plus récent : `lstat` (un lien → refus) ; lit `<nom>.tar` (100 Mo au plus) avec un lecteur ustar écrit ici ; types permis : fichier (`0`), dossier (`5`), en-tête pax (`x`, clés `path`, `mtime`, `atime`, `ctime` seulement) ; refus de tout chemin absolu, de `..`, de tout lien, périphérique ou fifo, d'un nom de plus de 255 octets, de plus de 20 000 fichiers ; l'archive `general-…` ne contient que `general/`, l'archive `prospects-…` que `prospects/` ; `manifeste.json` obligatoire, et l'empreinte de chaque fichier égale à celle du manifeste ;
   - extraction dans `<racine-travail>/<compartiment>/recu-<horodatage>/`, puis `precedent` supprimé (par une suppression qui ne traverse jamais un lien), `courant` → `precedent`, `recu-…` → `courant`, puis `a-indexer` ;
   - dans tous les cas, l'archive et son `.pret` sont supprimés ; une ligne `{ le, archive, compartiment, verdict, fichiers, octets, raison? }` s'ajoute au journal (jamais un contenu, jamais un chemin de prospect) ; code 0 si tout est reçu, 1 si une archive est refusée.
2. **`lib/savoir/index.ts`** (module pur, sans E/S) : `CLASSES` ; `normaliser(texte)` (minuscules, diacritiques retirés, mots de 2 signes et plus, mots vides français d'une liste fermée, pluriels en `s` et `x` ramenés) ; `decouper(chemin, texte, options?)` (titres Markdown puis paragraphes, 1 200 signes au plus, jamais au milieu d'une ligne, `debut` et `fin` en lignes, `id` = 16 premiers caractères hexadécimaux du SHA-256 de `chemin + debut + texte`) ; `construireIndex(passages)` (BM25, k1 = 1,2, b = 0,75, clés triées : mêmes octets pour les mêmes passages) ; `chercherIndex(index, question, { k, classes })` (`{ passage_id, racine, chemin, classe, debut, fin, extrait, score }`, extrait de 600 signes au plus pris dans le passage, tri par score puis id) ; `caviarder(texte)` (mêmes règles que l'export) ; `fusionnerScores(bm25, cosinus, poids)`.
3. **`scripts/savoir/indexer.mjs --compartiment=general|prospects|tous [--racine-travail=…]`** : supprime `a-indexer` d'abord ; lit `courant/` et son manifeste ; écrit `index/<compartiment>/index.json` (par `.part` puis renommage) et `etat.json` `{ compartiment, fichiers, passages, manifeste_sha256, synchronise_le, indexe_le, semantique, vecteurs }` ; pour `prospects`, l'index va sous `prospects/index/`, jamais à côté de `general`. Vecteurs : seulement si `semantique` est allumé, le compartiment `general`, l'hôte de `semantique.url` `127.0.0.1` ou `localhost` et le modèle sans suffixe `:cloud` ; sinon `semantique: eteinte` ou `refusee`, **sans aucune connexion** ; `POST <url>/api/embed` par lots de 16 [à vérifier : forme exacte de l'API d'embeddings d'Ollama 0.34.4 sur l'usine], vecteurs normalisés dans `vecteurs.bin` et `vecteurs.json` (ids, dimension, modèle), recalculés seulement pour les passages dont l'empreinte a changé. Écrit enfin une ligne `savoir index …` (compteurs, `manifeste_sha256`, code) à l'endroit que lit `presti-journal chef` [à vérifier sur 026-050 : le fichier exact].
