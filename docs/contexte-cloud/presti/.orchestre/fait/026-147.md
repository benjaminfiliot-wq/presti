## Contexte

Le Poste de contrôle (`/controle`) est l'écran d'où Benj dirige l'entreprise, souvent au téléphone. Presti y ajoute le pack pubs locales (149 €) : après la fabrication sur le poste, un pack est à l'état `fabriquee` et Benj doit **le regarder avant de le livrer** (les cinq premiers au moins, plan §1.1).

Les routes existent (fiche 15) :
- `GET /api/controle/packs` → `{ packs: [{ id, etat, artisan, paye_le, fabrique_le, livre_le, refaits, verifications, apercus?: { 'video-1.mp4': url, …, 'visuel-3.jpg': url } }] }` ; les adresses d'aperçu durent 600 s ;
- `POST /api/controle/packs/<id>` `{ action: 'livrer' }` (demande le mot de passe : reconfirmation de portée `artisan`) ou `{ action: 'refaire', consigne }` (10 signes au moins).

Le modèle d'écran est l'onglet Sites : `app/controle/Sites.tsx`, dont le geste « Mettre en ligne » appelle `apiDirection('/api/controle/sites/<id>', { method: 'POST', body: … }, true)` après un `window.confirm` (`:95-108`) ; le troisième argument `true` déclenche la demande de mot de passe (`app/controle/client.ts:20`).

L'enregistrement d'un onglet dans `app/controle/page.tsx` : le type `Onglet` (`:33`), la liste `ONGLETS` avec ses drapeaux (`:36-46`, par exemple `...(actif('siteCommande') ? (['sites'] as const) : [])`), `TITRES` (`:47`), `NAV` (`:49-60`) et le rendu (`:146`). Le domaine « Pilotage » modifie aussi ce fichier : l'orchestre sérialise les deux fiches.

Dépend de : 026-110 PASS (juge) et 15 PASS.

## Ce qu'il faut faire

1. **`app/controle/Packs.tsx`**, sur le modèle de `Sites.tsx` (mêmes classes, mêmes signaux `signaler`) :
   - la liste, du plus récent au plus ancien : artisan, état en clair (« Payé, à fabriquer sur le poste », « Fabriqué, à regarder », « Livré le … »), dates, nombre de retouches ;
   - pour un pack `fabriquee` : les trois films dans des `<video controls playsInline preload="metadata">` et les trois visuels dans des `<img>`, depuis les adresses d'aperçu ; si elles ont expiré, un bouton « Recharger » ;
   - le résumé des `verifications` du juge (critères verts ou non) ;
   - « Livrer » : `window.confirm('Le pack sera envoyé à l’artisan par courriel, avec des liens valables 30 jours.')`, puis `apiDirection('/api/controle/packs/' + id, { method: 'POST', body: JSON.stringify({ action: 'livrer' }) }, true)` ;
   - « Refaire » : un champ de consigne (10 signes au moins), puis `{ action: 'refaire', consigne }` ; pour un pack `livree`, le même bouton s'appelle « Retouche demandée par l'artisan » et n'apparaît que si `refaits = 0` et que le lien n'a pas expiré ;
   - pour un pack `payee` : la ligne « À fabriquer sur le poste : exporter, fabriquer, déposer » (aucun bouton : la fabrication ne tourne pas sur Vercel).
2. **`app/controle/page.tsx`**, cinq ajouts et rien d'autre : `'packs'` dans le type `Onglet` ; `...(actif('packPub') ? (['packs'] as const) : [])` dans `ONGLETS`, après les sites ; `packs: 'Packs pubs'` dans `TITRES` ; une entrée `NAV` (« Packs pubs », « Pubs locales à regarder et livrer ») ; la ligne de rendu `onglet === 'packs' ? <Packs role={role} signaler={signaler} />`.
3. **À ne pas faire** : aucune route, aucune bibliothèque ; ne pas toucher `Sites.tsx` ni `client.ts` ; pas de lecture automatique des films (le téléphone de Benj).
