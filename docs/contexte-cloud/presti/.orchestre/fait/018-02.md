# 018-02 — le juge d'usage de la démo

**Pourquoi.** Les juges de la démo Atelier Lestraque notaient des images du héros servies en local. Personne n'avait
cliqué « Demander un devis », ouvert le menu sur téléphone, visité une page commune ni mesuré les polices affichées :
c'est pourtant ce qui donnait l'impression d'un gabarit pas fini. Ce juge-là utilise le site comme un client.

**L'outil.** `node scripts/demo-usage-qa.mjs --url=<adresse de l'accueil> --sortie=<dossier>` (Node, ESM, Playwright déjà
installé dans node_modules). Il écrit `<dossier>/rapport.json` et ses captures dans `<dossier>`, affiche une ligne par
contrôle (✓ / ✗ + preuve courte), et sort avec le code 1 si au moins un contrôle échoue (0 sinon). Format du rapport :

```json
{ "url": "https://…/index.html", "date": "2026-09-14T…Z",
  "controles": [ { "id": "menu-mobile-ferme", "ok": false, "preuve": "…", "captures": ["menu-ouvert.png"] } ] }
```

**Les contrôles (identifiants exacts).**
- `menu-mobile-ferme` — contexte 390×844, tactile (`hasTouch`, `isMobile`). Tape le bouton du menu ; le panneau
  s'ouvre ; au centre du bouton, `document.elementFromPoint` doit renvoyer le bouton (ou un de ses enfants) et non le
  panneau ; tape à nouveau : le panneau doit être fermé (classe, `aria-expanded` ou visibilité). Captures : menu ouvert,
  puis après le second tap.
- `devis-mene-formulaire` — bureau 1440×900 puis téléphone : chaque lien ou bouton dont le texte contient « devis ». Après
  le clic, un `<form>` avec au moins deux champs doit être visible dans la fenêtre ; un lien `tel:` seul ne compte pas.
  Capture de l'écran après le clic.
- `polices-premier-passage` — contexte neuf, cache vide. Via CDP (`CSS.getPlatformFontsForNode`), les polices réellement
  rendues pour un paragraphe du texte courant, le h1, et le premier élément `.mono` s'il existe. Échec si l'une d'elles
  est une police système (Segoe UI, Arial, Helvetica, Consolas, Courier New, Times New Roman, Menlo, Roboto, San
  Francisco, -apple-system…) au lieu d'une police chargée par la page. La preuve nomme élément par élément la police vue.
- `voix-premiere-personne` — dans le texte visible de l'accueil, au moins une phrase à la première personne du singulier
  (« je », « j' », « mon », « ma », « mes » comme mots entiers). La preuve donne le décompte et un extrait.
- `page-commune` — suit le premier lien interne vers une page de commune (chemin contenant le nom du métier et une
  commune, par exemple `/menuisier-rennes/`) : la page répond 200, son h1 diffère de celui de l'accueil, et une image est
  visible dans le premier écran. Verdict libre, preuve obligatoire.
- `liens-internes-ok` — tous les liens de même origine de l'accueil (pages, ancres exclues) répondent 200.
- `console-sans-erreur` — aucune erreur de console ni exception de page pendant la visite de l'accueil. Verdict libre,
  preuve obligatoire (liste des erreurs vues, ou « aucune »).

**Fini quand** `verifier` passe. Il lance l'outil sur la démo en ligne (commit efda4a7, qui ne change pas pendant cette
tâche) : les quatre défauts connus doivent être vus (menu, devis, polices, voix), les liens internes doivent passer, et
chaque contrôle doit porter sa preuve.
