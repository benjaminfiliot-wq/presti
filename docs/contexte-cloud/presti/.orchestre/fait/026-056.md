## Contexte

**Pourquoi.** Depuis le 24/09 (rectification §3.3 et §3.12, décision R11, provisoire), le Livreur de sites tourne sur l'usine Oracle `presti-usine`, pour que la livraison tienne PC éteint (026-100 et 026-106 réécrites laissent cette fiche à créer : « tant qu'il n'a ni coffre à clés plafonnées ni routes de livraison, Actions est le chemin »). L'Atelier des maquettes, lui, a ses propres routes (`app/api/usine/atelier/*`, 026-097 réécrite) : ces deux routes-ci ne le servent pas. L'usine n'a **jamais** la clé de service Supabase : ses agents n'ont que leur jeton d'agent (026-040), limité à leurs types et à leurs tables. Pour déposer ses fichiers (le site généré), le livreur a besoin d'une « clé plafonnée » du stockage : ce sont ces deux routes. Elles ne signent d'URL que pour **la tâche que l'agent tient sous bail**, dans **un bucket privé à part** (`usine`), et dans **les limites de sa capacité**. Les fichiers vont ensuite directement de l'usine au stockage par l'URL signée : aucun gros corps ne traverse Vercel (offre Hobby jusqu'au premier site vendu (ce jour-là, Vercel Pro, 20 $ par mois : la seule dépense permise) : 4,5 Mo au plus par requête, 4 h de processeur par mois).

**Le contrat** (la copie du juge est `scripts/fixtures/026/usine-production/contrat-usine.json`, fiche 04) :
- capacité `livraison` (agent `livreur_usine`, tâches `livrer_site`) : 50 entrées au plus ; sortie de 300 fichiers au plus, 41 943 040 octets au total, 5 242 880 par fichier ; types `text/html`, `text/css`, `text/javascript`, `application/javascript`, `application/json`, `image/webp`, `image/avif`, `image/jpeg`, `image/png`, `image/svg+xml`, `font/woff2`, `text/plain`, `application/xml`, `text/xml` ;
- chemins : `usine/<tache>/entree/<nom>` (écrits par le serveur qui prépare la tâche) et `usine/<tache>/sortie/<nom>` (écrits par l'usine) ; `nom` relatif en `^[a-z0-9][a-z0-9._/-]{0,119}$`, sans `..` ni `//`.

**Ce qui existe** :
- `authAgent(req)` et `exigerTable(agent, table)` (`lib/agents/garde.ts`, 026-040) : `authAgent` rend l'agent (`nom`, `capacites`, `typesCrees`, `tablesEcrites`, `debitMinute`) ou un refus (`status`, `code`, `error`) ; `exigerTable` rend `null` ou un refus 403 ;
- les sept routes du bus (026-042), toutes en `runtime = 'nodejs'`, `dynamic = 'force-dynamic'`, qui ouvrent par `if (!actif('busAgents')) return 404`, puis `authAgent`, puis la validation. **Aucune** n'appelle `supabaseAdmin` elle-même (critère AR-8 de 026-042, qui lit **tout** `app/api/agents/**` : ces deux routes aussi) ;
- `supabaseAdmin` (clé de service, **côté serveur seulement**) et son client de stockage : `storage.from('usine').list(prefixe)`, `createSignedUrl(chemin, 900)`, `createSignedUploadUrl(chemin)` (qui rend `signedUrl` et `token`) ;
- `ops_stockage_octets()` (0098) : l'occupation de tout le stockage (1 Go, partagé) ;
- la migration de l'usine (fiche 05) : le bucket `usine` (privé, 8 Mo par fichier, types limités : une seconde barrière, tenue par Supabase) et `ops_tache_detenue(p_agent, p_id)`.

## Ce qu'il faut faire

1. **`lib/agents/usineLimites.json`** : les limites du contrat, par capacité : `{ "livraison": { "entrees_max": 50, "fichiers_max": 300, "octets_fichier_max": 5242880, "octets_total_max": 41943040, "types": [...] } }` (une autre capacité s'y ajouterait sans changer le code). C'est **la seule source** de ces nombres : les routes l'importent, et le tourneur de l'usine (fiche 07) le lit.
2. **`lib/agents/usineDepot.ts`**, où vit tout l'accès au stockage (jamais dans les routes) :
   - `tacheDetenue(agentNom, tacheId)` : `supabaseAdmin.rpc('ops_tache_detenue', { p_agent, p_id })` ; rend la tâche ou `null` ;
   - `entree(agent, tacheId)` : tâche détenue, sinon `{ status: 404, error: 'tache_introuvable' }` (**le même corps** pour une tâche inconnue, tenue par un autre agent ou au bail expiré) ; la capacité de la tâche doit être une clé de `usineLimites.json` (sinon 403 `capacite`) ; liste `usine/<tache>/entree/` ; plus de `entrees_max` objets pour la capacité de la tâche (50 pour la livraison) → 409 `trop_d_entrees`, aucune signature ; sinon une URL signée pour 900 s par objet ; rend `{ tache, entrees: [{ nom, url, octets }] }` ;
   - `depot(agent, tacheId, fichiers)` : tâche détenue (sinon 404 au même corps) ; la capacité de la tâche doit être une clé de `usineLimites.json` (sinon 403 `capacite`) ; validation **complète avant toute signature** : nombre, taille par fichier, total (413 s'il dépasse), type dans ceux de la capacité, nom (expression du contrat, ni `..`, ni `//`, ni `\`, ni caractère de contrôle, 120 signes au plus), noms deux à deux distincts, `sha256` de 64 signes hexadécimaux, `octets` entier positif ; puis `ops_stockage_octets()` : au-delà de 60 % de 1 073 741 824 octets → 507 `stockage`, en erreur → 503 ; **quand on ne sait pas, rien ne s'écrit** ; enfin une URL de dépôt signée par fichier, au chemin exact `<tache>/sortie/<nom>` du bucket `usine` ; rend `{ depots: [{ nom, url, jeton }] }` ;
   - aucune URL signée, aucun jeton, aucun nom de fichier d'entrée n'est écrit sur la console ; une erreur du stockage rend 502 `stockage_indisponible` sans détail.
3. **`app/api/agents/usine/entree/route.ts`** et **`app/api/agents/usine/depot/route.ts`**, POST seulement, `runtime = 'nodejs'`, `dynamic = 'force-dynamic'`, dans cet ordre : `if (!actif('busAgents')) return 404` ; `authAgent` ; `exigerTable(agent, 'taches')` ; corps de 16 Ko au plus (sinon 413) ; JSON valide et champs au bon type (sinon 400) : `{ tache: uuid }` pour l'entrée, `{ tache: uuid, fichiers: [{ nom, octets, type, sha256 }] }` pour le dépôt ; puis la fonction de `usineDepot.ts`, avec `agent.nom` (jamais un nom lu dans le corps). **Aucune mention** de `supabaseAdmin`, `ANTHROPIC`, `acq_`, `ops_decision_trancher` ni `ops_interrupteur_poser` dans ces deux fichiers.
4. **Ne pas faire.** Ne pas toucher `lib/flags.ts` ni `scripts/fermeture-e2e.mjs` (le drapeau `busAgents` existe déjà ; ces routes le lisent, comme les sept autres). Aucune politique de stockage, aucune migration (fiche 05). Aucun dépôt dans un autre bucket que `usine`. Aucune route qui lit ou efface `usine/<tache>/` pour le compte d'un consommateur : c'est le code serveur de la livraison (hors lot) qui le fait avec la clé de service.
