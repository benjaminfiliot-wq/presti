# 018-03 — la grille à l'aveugle

**Pourquoi.** La grille C1–C8 notait la démo Atelier Lestraque à 5/5 sur plusieurs critères, alors que Benj la juge « loin
encore du résultat ». Le juge savait laquelle des images était la démo. Pour le jugement final, il notera des planches
anonymes : il ne saura pas laquelle est la nôtre.

**L'outil.** `node scripts/grille-aveugle.mjs --demo=<dossier> --refs=<dossier> --ids=<id1,id2,…> --graine=<entier> --sortie=<dossier>`
(Node, ESM ; sharp est installé).
- Sujets : la démo (dans `--demo`, les fichiers `bureau-t06.png`, `bureau-t25.png`, `bureau-t50.png`, `bureau-t80.png`)
  et chaque référence de `--ids` (dans `--refs`, les fichiers `<id>-t0.png` à `<id>-t3.png`). Arrêt avec un message clair
  si une image manque.
- Ordre : les sujets reçoivent les lettres A, B, C… dans un ordre mélangé par un générateur pseudo-aléatoire initialisé
  par `--graine` (même graine → même ordre ; graine différente → ordre différent).
- Pour chaque sujet, `planche-<lettre>.jpg` : les quatre images côte à côte, redimensionnées à la même hauteur, sur fond
  neutre, avec la seule lettre en grand dans un coin. Largeur d'au moins 1600 px. Aucune métadonnée (pas d'EXIF, de XMP
  ni de commentaire), aucun nom de fichier ni d'identifiant dans l'image.
- `cle.json` : `{ "graine": 42, "sujets": { "A": "stellar-launch", "B": "demo", … } }`.
- `consignes.md` : les consignes pour un juge qui ne voit que les planches. Il note chaque lettre sur les huit critères
  C1 à C8 (reprendre les libellés et définitions de la section « La grille de comparaison » de
  plans/references-motionsites.md), de 1 à 5, sans savoir d'où viennent les sujets. Les consignes ne contiennent aucun
  identifiant de référence, ni les mots « démo », « demo », « Lestraque », « menuisier », ni le nom de la clé.
- Aucun autre fichier dans `--sortie` dont le nom contiendrait un identifiant, « demo » ou « lestraque ».

**Fini quand** `verifier` passe : il lance l'outil trois fois (graine 42 deux fois, graine 7 une fois) sur les images-clés
existantes et contrôle les planches, la clé, les consignes et le déterminisme.
