Exception à « la fiche seule » : Claude Code lit les cahiers du juge de ces huit fiches.

**Cinq règles fixent la méthode** (mémoires et rectification §4.0, §4.8) :
- **le juge capture lui-même** (`juge-capture-lui-meme`) : une capture livrée par un exécutant n'est pas une preuve ; le juge lance le serveur, se connecte, capture, compare ;
- **une preuve vide est un mensonge** (`preuve-vide-est-un-mensonge`) : 0 octet, image uniforme ou fichier absent = échec ;
- **juger un relais en continu** (`juge-relais-continu`) : la visibilité se mesure par `elementFromPoint` au centre de l'élément, pas par `IntersectionObserver` ;
- **le juge mesure le décor** (`juge-mesure-le-decor`) : une propriété géométrique (colonne de 300 px, pas de défilement horizontal) se mesure par la géométrie, jamais en comptant des pixels clairs ;
- **rien ne bouge sans un événement réel** (§4.0) : un personnage, une bulle, un carré de tapis ou un compteur ne change que si la réponse servie a changé. Le juge le mesure sur trois témoins indépendants : le compteur d'images dessinées que la carte expose (`data-images` sur `[data-station-carte]`), l'empreinte des pixels du canevas, et `document.getAnimations()` limité à la station.

L'écran se juge **sur des données connues** : Playwright sert depuis les jeux d'essai les réponses de `GET /api/controle/station?vue=…` (contrat de 026-092, validé par `s/contrat-vues.mjs`), de `GET /api/controle/tresorerie` (contrat de 026-059 : `{ encaisse: { jour, sept_jours, mois }, mrr, ventes_sites, depenses_mois, cout_ia, marge, tva, a }`) et de `GET /api/controle/pilotage?bloc=decider|appeler` (contrat de 026-068). Le reste du Poste (garde, session, rôle) tourne pour de vrai sur la copie au drapeau levé, avec le compte fondateur d'essai (aides `copieAvecDrapeau`, `serveurCopie`, `fondateurEssai` de `scripts/fixtures/026-pilotage/b/commun.mjs`, 026-066). Les routes réelles sont jugées par `station-route-qa` (026-067), `pilotage-route-qa` et `pilotage-gestes-qa` (026-066), et en recette.
