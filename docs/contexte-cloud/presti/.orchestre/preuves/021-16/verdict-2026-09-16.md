Le rejeu officiel de `node scripts/etapes-recit-qa.mjs` échoue sur ER-7 au téléphone : `img.eclate__eclate` est invisible et non décodée. Ce résultat n'est pas corrigible dans le périmètre de 021-16 sans annuler une décision ultérieure déjà livrée.

La cause est explicite dans `public/sites-demo/_kit/familles/telephone.css:63`, ajouté par la tâche 021-17 :

html.js #etapes figure.eclate img.eclate__eclate{display:none}

L'essai `decoding="sync"` sur l'image fixe n'a logiquement rien changé et a été entièrement annulé ; aucun fichier produit ne reste modifié par cette reprise.

Verdict : 021-16 est classée `refuse/` comme vérification devenue contradictoire après 021-17. Le produit téléphone livré n'est pas régressé pour satisfaire un ancien contrat.
