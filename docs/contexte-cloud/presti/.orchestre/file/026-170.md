## Contexte

Décision de Benj du 25/09, 11 h 45 : l'interface de l'écosystème est **Claw3D, avec des dessins pixel art, dans le Poste**. La voie (§0.1) : on **copie** dans presti le squelette 2D de Claw3D (l'hôte Phaser, le pont vers React, les types de carte, la recherche de chemin `astar2D`, le générateur d'avatar), sous sa licence MIT, à `app/controle/station/moteur/claw3d/` ; `Carte.tsx` le charge par `next/dynamic(..., { ssr: false })`. Pas d'iframe, pas de serveur Claw3D : l'usine n'est jamais exposée, et la garde fondateur s'applique à tout.

**Ce que ce juge protège** :
- **La règle de vérité** (§0.4) : Claw3D fait bouger ses agents au hasard (promenades, canapé après inactivité, vitesses tirées, lumières qui vacillent, bulles tirées d'une liste) ; Phaser se sème lui-même par `Date.now() * Math.random()`. Chez nous, **un agent ne bouge que sur un vrai événement**, et rien ne se dessine au repos. Le prototype B faisait trois fautes : tout agent inactif au Repos, des chiffres peints dans le décor, et Phaser réveillé à chaque appel du pont.
- **La sécurité** (§0.5) : aucune route de Claw3D, aucune passerelle, aucun WebSocket ; la CSP de Presti inchangée ; le moteur ne démarre qu'après la garde ; les thèmes jamais servis sur le domaine d'un artisan.
- **Le poids** (§0.8) : Phaser 3.90 fait 307 Kio en gzip ; le budget de 340 Ko du midi était faux ; la mesure se fait **dans le navigateur**, sur les `.js` réellement demandés (`scripts/budget-perf.mjs` ne voit pas ces morceaux chargés à la demande).
- **La licence** : la notice MIT et `PROVENANCE.md` (commit 0565b78) ; aucun `.glb`, aucun `multiavatar`.

**Où tourne le juge** (INDEX, « Comment lire », décision du 25/09) : les critères statiques (lecture du source) tournent là où le juge est lancé ; toute partie qui demande un navigateur, Phaser ou un serveur de la copie tourne **sur l'usine** (le PC n'a pas 1 Go libre ; Phaser pèse 148 Mo). Lancé ailleurs (nom d'hôte autre que `presti-usine`), le juge se relance lui-même par `node scripts/usine.mjs executer --nom=claw3d [--rapatrier=.orchestre/preuves/<fiche jugée>/] -- node scripts/station-claw3d-qa.mjs <mêmes options>` et rend sa sortie et son code tels quels ; usine injoignable → code 2 (« usine injoignable »). Aucun `verifier` ne lance donc `scripts/usine.mjs` (CV-2 de 026-001 ; même règle que 026-165).

**La session simulée** : l'usine n'a ni `.env.local` ni clé de service, et ne doit pas en avoir. Les juges de rendu (celui-ci et `station-ecran-qa`, 026-172) servent la copie avec des `NEXT_PUBLIC_*` factices, posent une session Supabase factice dans le `localStorage` de la page, et interceptent l'hôte Supabase et `/api/controle/**` (réponses tirées des jeux d'essai, validées par `s/contrat-vues.mjs` de 026-067) : **aucun compte réel, aucune clé**.
