# 025-10 — contre-vérifier les juges de la série 025

## Contexte

Claude Code a écrit les juges de la série (025-01). Un juge qu'on n'a jamais vu échouer sur une vraie faute ne prouve rien. Le 16/09, deux juges assouplis ont laissé passer 023-01 et 023-02 avec 0 ligne. Cette fiche est la contre-vérification indépendante, sur le modèle de 023-03 (`.orchestre/en-cours/023-03.md`). Elle se lance quand 025-02 à 025-07, 025-09 et 025-11 sont PASS.

Chaque juge accepte `--racine=<dossier>` : il lit et génère à partir de ce dossier.

## Ce qu'il faut faire

1. Pour chaque juge : copier le dépôt utile dans `.orchestre/travail/025-10/<juge>/` (sans `node_modules` ni `.git`), lancer le juge sur la copie intacte (**témoin : code 0 attendu**), puis sur chaque copie mutée (**code ≠ 0 attendu**, avec le critère nommé).
2. Mutations minimales à couvrir :
   - **promesses-qa** : « moins d’une minute » avec l'apostrophe typographique remis dans une copie de `app/manifest.ts` ; « moins d&apos;une minute » dans `app/page.tsx` ; « Présence en ligne soignée » dans `lib/plans.ts`.
   - **constructeur-ferme-qa** : `constructeurSite: true` ; le bloc `SITE_A_LA_DEMANDE` retiré de `/profil` ; la route qui répond 410 ; `rendreCredit(` retiré de la route.
   - **maquette-qa** : une sortie sous `public/` ; « depuis 2011 » ou « 15 ans » dans le texte de la maquette ; un `<blockquote>` rempli ; un fichier d'une démo gelée modifié ; une page blanche (capture uniforme).
   - **formulaire-site-qa** : `data-demo` remis sur le formulaire ; le piège `website` retiré ; le bloc de repli retiré ; l'appel à `artisanParAncienSlug` retiré d'une copie de `app/api/leads/route.ts`.
   - **verrou-site-qa** : la ligne `site_origine` retirée ; la ligne `new.plan := old.plan;` retirée.
   - **webhook-muet-qa** : la branche `orphelin` retirée ; la branche qui lève une erreur au lieu de répondre 200.
   - **parcours-commande-qa** : la citation rendue facultative ; un parcours de 200 signes accepté ; `PRIX_SITE_CENTS` changé.
3. Écrire `mutations.md`.
4. **Si une mutation passe, NE PAS corriger le juge.** L'écrire en tête du rapport et sortir en code 1. Ne jamais modifier un juge, un jeu d'essai, ni le dépôt en place.
5. Pour les critères qui mesurent un temps ou lancent un navigateur, attendre qu'aucun autre `node … -qa.mjs` ne tourne.
