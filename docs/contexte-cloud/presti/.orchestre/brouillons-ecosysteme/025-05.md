# 025-05 — le constructeur de site sort de « Ma page »

## Contexte

Presti fait désormais les sites lui-même, sur commande à 300 € (`lib/siteCommande.ts:9-11`). L'éditeur de site de `/profil` n'a plus de raison d'être et ouvre une porte gratuite. Mais le bloc « Votre site web » (`app/profil/page.tsx:419-452`) contient aussi, dans sa branche « pas de site », le seul bouton « Commander mon site » de la page (`:442-450`). Ce bouton doit rester.

Trois contrôles existants dépendent de ce que vous changez :
- `scripts/fermeture-e2e.mjs` refuse tout drapeau absent de sa carte (`:258-260`), et une route fermée par un drapeau doit y répondre **404** (`:214`), pas 410 ;
- `scripts/site-sorti-des-formules-verifier.mjs:48` exige aujourd'hui `site_active` dans `/profil` ;
- `scripts/audit-final-e2e.mjs:153-155` exige que `app/api/site/generate/route.ts` contienne `signalerPanneIA(` et `rendreCredit(`.

## Ce qu'il faut faire

1. **`app/profil/page.tsx`, retirer :**
   - l'apparence et l'usage de `StyleAvance` ;
   - les réalisations (`PortfolioUpload`) ;
   - dans « Votre site web », la branche éditeur : niveaux (`site-tiers`, « Inclus dès … »), « Rédiger avec l'IA », composeur, textes du site, case « Mon site est publié », aperçu, avant/après (« Inclus dans l’offre Signature ») ;
   - le bouton « Réinitialiser le site » ;
   - les clés `site_active`, `site_tier`, `site_contenu`, `site_layout`, `realisations` et `avant_apres` de l'objet enregistré (`:196-227`).

   Ne supprimer aucun fichier de composant : seulement leur usage ici.
2. **Garder :**
   - le bloc `SITE_A_LA_DEMANDE`, affiché à tous, avec son bouton sous `actif('siteCommandeVente')` ;
   - le lien, l'interrupteur « page active », le logo, la bio, la zone, les horaires, les prestations, les contacts, le domaine et la suppression du compte ;
   - « Supprimer le site », seulement si le site enregistré est actif. Après la migration 0093, c'est le seul moyen pour le titulaire d'un site historique de le retirer lui-même (`app/api/donnees/route.ts:114-121`).
3. **La promesse de `:309`.** « reçoit une réponse en moins d'une minute » devient une phrase vraie, par exemple : « Chaque contact arrive dans Presti, avec une réponse prête en moins d'une minute. » En mode assisté, par défaut, Presti prépare la réponse et l'artisan l'envoie (`lib/plateformeConfig.ts:45`, `:184`).
4. **`lib/flags.ts`.** Ajouter `constructeurSite: false`, avec un commentaire daté qui dit ce qu'il ferme.
5. **`app/api/site/generate/route.ts`.** La première instruction du `POST` est `if (!actif('constructeurSite')) return NextResponse.json({ error: 'Introuvable' }, { status: 404 })`. Le reste du fichier reste intact.
6. **`scripts/fermeture-e2e.mjs`.** Ajouter à la carte exactement `'constructeurSite': ['route', '/api/site/generate', 'POST', 'app/api/site/generate/route.ts'],` et rien d'autre.
7. **`scripts/site-sorti-des-formules-verifier.mjs:48`.** Remplacer seulement cette assertion par : « app/profil : plus d'éditeur de site ; le site à la demande reste proposé ». Elle exige `SITE_A_LA_DEMANDE` et refuse `genererSite`, `site-tiers`, `StyleAvance` et `/api/site/generate`. Rien d'autre dans ce fichier.
8. **`lib/aide.ts`.** Réécrire l'entrée « profil » (`:247-267`) sans apparence, thème, réalisations, niveau de site ni « Rédiger ou régénérer le site ». Retirer les bulles d'aide des champs retirés, seulement celles qu'aucun autre fichier de `app/` n'utilise.
9. `npm run typecheck` doit être vert.
