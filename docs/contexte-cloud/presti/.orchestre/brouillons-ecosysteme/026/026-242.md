## Cahier du juge (`scripts/comptable-qa.mjs`)

- **CPT-1** Contrat : le module s'importe sans effet de bord ; aucune méthode d'écriture Stripe (`create`, `update`, `del`, `cancel`) n'apparaît dans son source, lu par le juge lui-même (grep du texte, pas une déclaration du module).
- **CPT-2** Rapprochement : chaque paiement Stripe réussi se relie à une commande ou un abonnement par son identifiant externe ; un paiement sans commande correspondante sort dans `orphelins` (jamais silencieusement ignoré, jamais compté en recette) ; un paiement dupliqué (même id Stripe reçu deux fois) n'est compté qu'une fois ; un écart d'un centime ou plus entre le montant Stripe et le montant de la commande sort dans `ecarts`, jamais corrigé tout seul.
- **CPT-3** Seuil de franchise : le cumul de l'année civile se recalcule à partir des **seules** recettes rapprochées (jamais des `orphelins` ni des `ecarts` non résolus) ; à 90 % du seuil → `approche_seuil` ; au-delà → `seuil_depasse` avec la date exacte de la recette qui fait dépasser ; un seuil sans source datée (comme l'exige 026-059 pour le seuil 2026) fait échouer le critère — jamais un nombre codé en dur sans date.
- **CPT-4** Montants préparés : `preparerDeclaration(periode)` rend `{ periode, recettes, tva: 0, source, prepare_le }` ; `tva` vaut toujours 0 (franchise en base) ; aucune fonction du module ne contient d'appel réseau vers un service de dépôt, de paiement ou d'administration fiscale — le juge grep le source (`fetch`, `axios`, `http.request`) et n'en trouve aucun ; aucun nom de fonction ne contient « declarer » ou « payer » sans que le juge vérifie qu'elle est pure (aucun effet de bord).
- **CPT-5** Mentions de TVA : aucune fonction n'écrit dans un gabarit de facture, une CGV ou une mention légale ; le sabotage qui ajoute une telle écriture est attrapé avec son propre nom.
- **CPT-6** Libellé sous D1 : le seul appel à un moteur de langage passe par `MOTEUR_DE` avec `personnelles: true` (Codex, jamais un moteur `:cloud` ni gratuit) ; sans Codex disponible, le module rend un libellé de gabarit fixe (jamais une attente qui bloquerait le calcul du chiffre, jamais un appel à freellmapi, Ollama Cloud ou Perplexity pour cette tâche).
- **CPT-7** Deux chiffres, un écran : le total qu'une future tuile « Recettes » afficherait et celui que rend `preparerDeclaration` viennent de la **même** fonction interne ; le juge appelle les deux chemins publics du module sur le même jeu d'essai et exige l'égalité au centime.
- **CPT-8** Journal : chaque rapprochement écrit une ligne d'événement (type, montant, jamais un numéro de carte ni un secret Stripe) ; deux passages sur le même jeu d'essai ne dupliquent pas la ligne (idempotence par période).
