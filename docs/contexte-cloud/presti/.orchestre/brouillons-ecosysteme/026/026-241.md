## Contexte

Tout le code de la couche Savoir est jugé sur des jeux d'essai et contre-vérifié (026-240) ; rien n'est encore installé ni allumé. Cette fiche fait les gestes qui touchent l'usine et le poste, un par un, chacun couvert par un « oui » de Benj consigné dans `mise-en-service.md`, puis allume les interrupteurs par un commit de Claude Code (l'usine les lit dans `/srv/presti-agents`).

Ce qui reste éteint à la sortie de cette fiche, et pourquoi :
- **`semantique`** : aucun modèle d'embeddings sur l'usine ; `tirer.sh` plafonne à deux modèles. Un troisième (petit, local, multilingue [à vérifier : taille et licence du modèle retenu, disponibilité ARM]) attend un « oui » explicite de Benj ; sans lui, la recherche est plein texte, et c'est suffisant.
- **`recherche_web`** : `FIRECRAWL_API_KEY` n'est pas dans la liste fermée `NOMS_PERMIS` du coffre de l'usine (026-050) ni dans les règles de référence de son juge (026-048). L'y ajouter est un préalable de Claude Code, hors série, jugé par `usine-socle-qa` ; d'ici là, la recherche web rend `indisponible`, et la lecture d'une adresse connue retombe sur le lecteur poli de 026-020.
- **`perplexity`** : plan et coût non constatés ; fermé tant que `reglages.json` ne porte pas un plan, un coût de 0 € et une date de constat de moins de 30 jours (et la clé au coffre, même préalable que Firecrawl).
