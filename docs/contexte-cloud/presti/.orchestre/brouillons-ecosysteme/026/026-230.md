## Ce qu'il faut faire

1. **`node scripts/savoir/exporter.mjs [--sources=docs/savoir/sources.json] [--sortie=<dossier>] [--a-sec]`** :
   - la sortie par défaut est `C:/Users/benja/AppData/Local/presti-savoir/export` ; une sortie dans le dépôt presti ou sous l'une des racines de `sources.json` → code 2, rien d'écrit ;
   - le parcours ne **descend jamais** dans un dossier exclu et teste les exclusions sur le chemin **avant** toute ouverture ; un lien symbolique n'est jamais suivi ;
   - pour chaque fichier retenu : exclusions, puis règles `prospects`, puis la première ligne de `sources` qui répond ; hors liste → compté, jamais lu ; format hors liste → `format_non_lu` ; au-delà de 2 Mo → `trop_gros` ;
   - contenu : `chercherSecrets` de `scripts/instantane-quotidien.mjs` (importé, jamais recopié ni modifié) ; un secret → fichier écarté entier, le rapport ne garde que le chemin et le nom du motif ;
   - classes `public` et `interne` : caviardage (adresse, numéro, SIREN ou SIRET valide) et reclassement en `prospects` à partir de 5 coordonnées ; mémoire : noms `exclusions_memoire` écartés, lignes correspondantes retirées de `MEMORY.md` ;
   - écrit dans `<sortie>.part` : `general/fichiers/<racine>/<chemin>`, `general/manifeste.json` (`version`, `exporte_le`, `sources_sha256`, `fichiers[]`, `prospects: { fichiers: <n> }`), `prospects/fichiers/…`, `prospects/manifeste.json`, `rapport.json` (compteurs par classe, exclusions par motif, secrets par chemin, caviardages, `trop_gros`, `format_non_lu`, `hors_liste`) ; puis remplace `<sortie>` par renommage ; au-delà de 80 Mo au total : code 1 et `<sortie>` intacte ;

2. **`node scripts/savoir/envoyer.mjs [--sortie=<dossier>] [--a-sec]`** :
