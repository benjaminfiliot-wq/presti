## Contexte

**Décision de Benj du 24-25/09 : aucun achat** (« trouve alternative gratuite et puissante, pas de négociation possible »). Les agents n'ont donc ni la clé du produit (règle 3 du plan : le 04/09, une seule clé vidée a éteint tout Presti), ni une clé payée pour eux. Ils ont deux moteurs gratuits :
- **`codex`** : GPT-6 (sol pour la rédaction et le rejugement, luna pour le léger) sur l'abonnement ChatGPT de Benj, **0 € de plus**. Il tourne **sur l'usine** : `CODEX_LANCEUR=/usr/local/bin/presti-ia-modele` (installé par 026-148) passe chaque demande à la file du compte `chef-modele`, déjà connecté à Codex, réseau coupé, sans droit sur le coffre (026-129). C'est le seul moteur permis pour une donnée personnelle (prospect, client) ;
- **`freellmapi`** : `127.0.0.1:3001` sur l'usine, compatible OpenAI, qui bascule seul d'un fournisseur gratuit à l'autre ; pour le travail de masse **sans** donnée personnelle (les douleurs ; la veille des pubs passe à Codex, contre-revue du 25/09 au soir). Jamais une donnée de prospect.

Le contrat exact (constantes, `MOTEUR_DE`, `creerLecteur`, argv de Codex, corps de freellmapi, coût à 0 €) est dans le contexte de 026-041 : ce module le suit mot pour mot.

**Ceux qui l'attendent**, et ce qu'ils font sans moteur :
- 026-094 (Standard) : `creerLecteur('standardiste')`, appelé **sur l'usine** par `scripts/agents/passes-modele.mjs` (contre-revue du 25/09 au soir) ; la route Vercel du Standard n'importe plus ce module : elle classe en code et attend l'usine (30 min, puis « à lire ») ;
- 026-089 (second juge et rejugement du Facteur) : `creerLecteur('facteur')` et `creerLecteur('facteur', { modele: 'rejuge' })`, appelés **sur l'usine** par le même script ; `null` → aucun avis, donc aucune approbation (fermé par défaut) ; l'approbation reste sur Vercel (route `usine/facteur/avis`) ;
- 026-093 et 026-100 (rédacteur des sites) : `creerLecteur('redacteur_site')` ; `null` → `--sans-ia` ;
- 026-106 (GitHub Actions) : jamais de moteur, `--sans-ia`.

Le coût d'un appel s'inscrit dans le bus : `ops_cout_ajouter(p_agent, p_fournisseur, p_montant_eur, p_detail, p_tache)` rend le total du jour et met l'agent en pause au-delà de son plafond (0098, 026-013), par la fonction de `lib/agents/bus.ts` qui l'appelle (026-040). **Tous les plafonds valent 0** (026-060) : le module inscrit 0 €, avec son moteur et son modèle (ce que la station affiche, 026-070, 026-076, 026-092) ; le premier euro inscrit mettrait l'agent en pause et ouvrirait une décision d'argent. **L'agent doit exister dans `ops.agents`** (graines de 0105, 026-060) : un agent absent rend `ops:agent_inconnu`, que `llm.ts` traite comme un échec d'inscription (l'appel suivant est refusé). C'est voulu : un appel qu'on ne peut pas compter ne se fait pas.

Réservée à Claude Code : moteurs, données personnelles et argent (`CLAUDE.md:23`, consigne du 24/09).
