## Contexte

Claude Code a écrit les juges de la station Claw3D **avant** la production (décision 8 de Benj) : `station-planche-qa` (026-168), `station-claw3d-qa` (026-170), `station-themes-qa` et `ecommerce-reservee-qa` (026-171), `station-ecran-qa` (026-172). Un juge qu'on n'a jamais vu échouer sur une vraie faute ne prouve rien : le 16/09, deux juges assouplis ont laissé passer 023-01 et 023-02 avec 0 ligne. CV-6 de 026-001 exige que chaque `scripts/*-qa.mjs` du périmètre d'une fiche de juges soit nommé dans une fiche de mutations.

Chaque juge accepte `--racine=<dossier>` et, sur l'usine (nom d'hôte `presti-usine`), tourne sur place, sans se relancer.

## Ce qu'il faut faire

1. Pour chaque mutation : copier les fichiers utiles du dépôt dans `.orchestre/travail/026-191/<mutation>/` (sans `node_modules`, `.git` ni `.next` ; jonctions vers `node_modules` et `public`, retirées ensuite), lancer le juge sur la copie intacte (**témoin : code 0 attendu**, une fois par partie), puis sur chaque copie mutée (**code ≠ 0 attendu, avec le critère nommé dans une ligne en échec**).
2. **Mutations minimales à couvrir** (une copie par mutation, chacune **un** remplacement de texte exact) — les pièges du §0.9, et une entrée par partie :
   - **station-claw3d-qa** : la notice MIT retirée de `LICENSE-claw3d.txt` (CL-1, `provenance`) ; Phaser importé dans `app/controle/layout.tsx` (CL-3) ; un `Phaser.Math.Between` caché dans la scène (CL-6 ou CL-5, `verite`) ; « inactif → Repos » remis dans la scène (CL-7) ; un chiffre peint dans le décor (CL-8) ; le pont appelé à chaque lecture, sans comparer la signature (CL-9, `repos`) ; `<Carte />` monté avant la réponse de `vue=direct` (CL-10, `garde`) ; un `fetch` vers un hôte externe (CL-11, `csp`) ; Phaser importé dans une page hors station (CL-12, `poids`) ; l'échelle comptée en pixels CSS (CL-13, `pixel`) ; la perte de contexte non rattrapée (CL-14, `contexte`) ; la salle réservée prise pour destination (CL-15, `grille`) ; `station\/.*` retiré de `CHEMINS_APP_PRESTI` (CL-16, `hygiene`) ;
