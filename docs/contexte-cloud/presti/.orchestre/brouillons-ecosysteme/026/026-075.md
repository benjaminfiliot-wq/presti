## Contexte

Après un « oui », les agents envoient en moins de 24 h une **vidéo de 15 à 20 s qui fait défiler le site au nom de l'artisan**, avec le lien privé (rectification §3.7) : Hugo (0:26-0:29,8) et Jt (0:40-0:44) offrent une vidéo, pas des captures. Par e-mail, la page privée la montre ; sur Instagram, elle part en pièce jointe par son adresse.

**Pourquoi un panoramique et pas un enregistrement d'écran** : l'enregistrement vidéo de Playwright avance de 0,05 à 0,8 s sur l'horloge de la page, et cette avance dérive (mémoire `playwright-video-horloge`) ; un défilement filmé saccade selon la charge de la machine. Une **capture pleine page** puis un **panoramique vertical calculé par ffmpeg** donnent une vidéo fluide, de durée exacte, identique d'une fois sur l'autre, légère pour l'usine (2 cœurs).

**Les contraintes du lieu** : l'usine ne commite jamais ; le script écrit seulement dans le dossier de sortie qu'on lui donne (hors du dépôt) ; il ne lit aucun secret ; `spawn` sans `shell: true` (mémoire `spawn-windows-shell-ffmpeg` : le `|` d'un filtre lu comme un tube).

## Ce qu'il faut faire

1. **Usage** : `node scripts/agents/maquette-video.mjs <dossier du site> --sortie=<fichier.mp4> [--duree=18]`. Le script exporte aussi `fabriquerVideo({ dossierSite, sortie, duree, lancerNavigateur, ffmpeg })` et ne s'exécute seul que lancé directement.
2. **Servir le site** : un serveur `node:http` sur `127.0.0.1`, port libre, qui ne sert que les fichiers du dossier (aucun chemin qui en sort : `..` refusé) ; arrêté dans un `finally`.
3. **Capturer** : Chromium de Playwright, sans tête, fenêtre de 390 × 844 à l'échelle 2 (téléphone), **toutes les requêtes vers un autre hôte que `127.0.0.1` bloquées** (`page.route`), animations et transitions coupées par une feuille injectée (`* { animation: none !important; transition: none !important; scroll-behavior: auto !important; }` ; mémoire « scroll-behavior smooth »), attente du chargement des polices et des images, puis une capture **pleine page** en PNG. Une page de moins de 1 200 px de haut (rien à faire défiler) → code 3 « page trop courte ».
4. **Monter** : ffmpeg, arguments en tableau, sans shell :
   - entrée : la capture, en boucle, pendant `duree` secondes (18 par défaut ; bornes 15 et 20) ;
   - filtre : une tenue de 1,5 s en haut, un défilement régulier jusqu'en bas, une tenue de 1,5 s en bas (`crop` dont le `y` est une expression du temps), puis `scale=720:-2`, `fps=30`, `format=yuv420p` ;
   - sortie : `libx264`, `-preset slow`, `-crf` choisi pour tenir sous 3 Mo (en commençant à 28 et en montant de 2 tant que le fichier dépasse 3 Mo, trois essais au plus, sinon code 4), `-movflags +faststart`, **aucune piste son** (`-an`), aucune métadonnée de titre ni d'auteur (`-map_metadata -1`).
5. **Sortie console** : la durée, le poids et le code, rien d'autre (aucun nom, aucun domaine). Codes : 0 fait, 2 usage (dossier absent, sortie dans le dépôt hors `.orchestre/travail/`, ou sous `public/`), 3 page trop courte, 4 trop lourde, 5 ffmpeg ou Chromium absent, 1 autre.

## Cahier du juge (`maquette-video-qa`, écrit en 026-071)

Le juge lance lui-même le script sur le site d'essai et mesure le fichier.
- **MV-1** `scripts/agents/maquette-video.mjs` existe, exporte `fabriquerVideo`, et ne lance rien quand il est importé.
- **MV-2** sur le site d'essai : code 0 ; `ffprobe` lit un seul flux vidéo `h264`, `yuv420p`, 720 de large, de 15,0 à 20,0 s, 30 images par seconde ; **aucun flux audio** ; le fichier fait 3 Mo au plus ; l'atome `moov` précède `mdat` (lecture continue).
- **MV-3** le mouvement : 10 images extraites par le juge à intervalles réguliers ; au moins 7 sont différentes deux à deux ; la première et la dernière diffèrent ; aucune n'est noire (luminance moyenne au-dessus de 10 sur 255) ; les images de la première seconde sont identiques entre elles (la tenue en haut) ; aucune plage figée de plus de 2 s hors des deux tenues.
- **MV-4** déterminisme : deux fabrications de suite donnent des vidéos de même durée et de mêmes dimensions, et des images extraites identiques aux mêmes instants.
- **MV-5** le serveur d'essai du juge consigne les requêtes : aucune vers un autre hôte (le site d'essai en contient une, qui doit être bloquée) ; le serveur du script refuse `../`.
- **MV-6** la page toute blanche → une vidéo jugée figée (MV-3 en échec : c'est l'autocontrôle) ; la page de 800 px → code 3 ; une sortie sous `public/` → code 2 ; sans ffmpeg dans le `PATH` → code 5.
- **MV-7** lecture du source : aucun `shell: true`, arguments de ffmpeg en tableau, aucun `process.env` hors `FFMPEG` et `PLAYWRIGHT_BROWSERS_PATH`, aucun `fetch(` vers l'extérieur.
