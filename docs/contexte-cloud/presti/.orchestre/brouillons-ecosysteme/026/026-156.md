## Contexte

Un pack payé (état `payee` dans la table `packs_pubs`) se fabrique **sur l'usine** (contre-revue du 25/09 au soir : tourneur des pubs, 026-200 ; le poste en repli), jamais sur Vercel : le rendu HyperFrames, ffmpeg, OpenCV et la transcription tournent en local, là où le script tourne. **Cette étape tourne PC éteint** ; le délai de livraison annoncé dans les CGU 3 ter reste une marge.

Ce qui existe :
- le gabarit `gabarits-pubs/locale/` et `scripts/pack-pub/instancier.mjs <gabarit> <dossier-pack> <sortie>` (fiche 11), qui lit les photos déjà préparées dans `<dossier-pack>/photos/` ;
- `scripts/pack-pub/textes.mjs <dossier-pack> [--meta-logement=<fichier>]` (fiche 13), qui écrit `sortie/textes.md` et `sortie/fiche-10-min.md`, et sort en code 3 tant que la catégorie « Logement » n'est pas vérifiée ;
- `scripts/visages-qa.mjs <images…> --attendu=0` (fiche 09) : code 1 dès qu'un visage est trouvé ;
- `sharp` dans `node_modules`, ffmpeg 8.1.1 et le CLI `npx --yes hyperframes@0.8.33` (`check`, `render`, `snapshot`) sur le poste.

Le contrat du dossier est dans `gabarits-pubs/locale/contrat.json` : `pack.json` (`{ pack_id, matiere }`), `voix.mp3` si la voix est de synthèse, puis ce que tu écris : `photos/NN.jpg`, `manifeste-entrees.json`, `hf/video-1..3/`, `hf/visuel-1..3/`, `sortie/` (trois `video-N.mp4`, trois `visuel-N.jpg`, `textes.md`, `fiche-10-min.md`).

**Pourquoi vérifier les octets.** Les photos arrivent par `POST /api/media`, qui déduit le type de `?ext=` sans lire le fichier (`app/api/media/route.ts:67-68`) : un fichier nommé `.jpg` peut être n'importe quoi. Seul un décodage réel fait foi. Les photos de chantier portent souvent la position GPS de la maison du client : aucune métadonnée ne doit sortir.

Dépend de : 026-126, 026-153 et 026-154 PASS.

## Ce qu'il faut faire

`node scripts/pack-pub/fabriquer.mjs <dossier-pack> [--meta-logement=<fichier>]`, dans cet ordre, chaque étape arrêtant tout en cas d'échec (code 1, message qui nomme le fichier) :
1. **Lire** `pack.json` ; refuser un dossier sans `pack_id` ou sans `matiere.photos`.
2. **Préparer les photos** : chaque `url` est soit un chemin local, soit une adresse `https://…/storage/v1/object/public/artisan-media/…` ; téléchargement borné (15 Mo, 20 s) ; décodage par `sharp` : format `jpeg`, `png` ou `webp` seulement ; `rotate()` selon l'orientation, grand côté ramené à 2 160 px au plus, écriture en `photos/NN.jpg` (qualité 90) **sans aucune métadonnée**.
3. **Personnes** : `visages-qa --attendu=0` sur chaque photo marquée `personnes: false` ; un visage → code 1 « visage détecté sur photo NN sans accord », et rien n'est écrit dans `sortie/`.
4. **Manifeste** `manifeste-entrees.json` : pour chaque photo `{ fichier, sha256, source, role, personnes, accord_personnes }`, le logo et la voix de même.
5. **Voix** (si `synthese`) : `voix.mp3` est produite **avant** `fabriquer.mjs`, **par défaut par la voix locale `ff_siwis`** (voie gratuite du 25/09 ; 026-157 le signale), avec `licence-voix.md` dans le dossier du pack ; jamais ElevenLabs (contre-revue du 25/09 au soir : aucune offre payante décidée) ; `fabriquer.mjs` ne l'appelle jamais. Elle est normalisée **seule**, avant tout montage : `loudnorm=I=-14:TP=-1.5:LRA=11`, 48 kHz (mémoire `loudnorm-apres-un-carton-muet`) ; c'est cette version qui entre dans les projets et dans le manifeste.
6. **Instancier** `avant-apres` (ou la seconde variante de `chantier` sans paire), `chantier`, `artisan-ville` en `hf/video-1..3`, et `visuel` trois fois avec trois photos différentes en `hf/visuel-1..3`.
7. **Contrôler** : `hyperframes check` sur chaque projet ; une erreur arrête tout.
8. **Rendre** : `hyperframes render --quality high` → `sortie/video-N.mp4` ; si le débit mesuré par `ffprobe` est sous 3 200 kbps, réencoder en H.264 (CRF 18, débit maximal 4 Mbit/s, son AAC recopié) ; 8 Mo au plus par film.
9. **Visuels** : `hyperframes snapshot hf/visuel-N` à 0,5 s → JPEG 1080×1080, qualité 85, sans métadonnée, 1 Mo au plus.
10. **Textes** : `node scripts/pack-pub/textes.mjs <dossier-pack>` en transmettant `--meta-logement` s'il est donné ; son code 3 est rendu tel quel (catégorie « Logement » non vérifiée : geste de Benj).
11. **Résumé** : une ligne par fichier de `sortie/` avec son poids ; aucun appel réseau autre que le téléchargement des photos ; aucune clé lue.

À ne pas faire : ne pas modifier le gabarit ni `instancier.mjs` (écris une question si l'un d'eux bloque) ; aucune image générée, aucune banque d'images ; ne pas écrire hors du dossier du pack et de `.orchestre/travail/`.
