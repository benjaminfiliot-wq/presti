## Contexte

Depuis la décision de Benj du 24/09 (rectification §3.1), **les agents envoient**. Le Facteur fait juger chaque envoi préparé par J1 (026-065), J3 et le second juge (026-083) et l'approuve avec les trois verdicts. Depuis la voie gratuite du 25/09, il envoie lui-même les messages sollicités par le **Gmail de prospection** (`porteurs/gmail.ts`, `email_sollicite`) et les réponses Meta ; le premier contact, lui, passe par le **formulaire de contact du site**, que le **porteur** soumet sur l'usine dans un vrai Chromium (026-095), jamais le Facteur. La base tient les règles en seconde serrure (0099, 026-034 ; 0106, 026-061 ; 0111, 026-063). Les **disjoncteurs** arrêtent seuls une technologie de formulaire, le canal du formulaire, le Gmail, un modèle ou Meta, en **compteurs absolus** (voie gratuite §3.2). Les **jauges** montrent, et font respecter, les quotas de chaque canal et de chaque fournisseur.

Tout se juge sur des doublures qui enregistrent chaque requête : un serveur local de pages de formulaire, un faux serveur SMTP, un faux client IMAP, une API Meta factice. Le porteur se juge aussi en vrai : Chromium arm64 est lancé **sur l'usine**, jamais sur le poste de 8 Go.

Règle 1 de `CLAUDE.md:23` : Claude Code écrit les juges, jamais l'exécutant qui les utilise. Les options communes (`--racine`, `--auto-controle`, une ligne par critère, module absent → échec du premier critère avec son identifiant) sont celles de 026-016 §3.
