## Contexte

Le générateur lit un `contenu.json` **v2 à pages** (`public/sites-demo/generer.mjs:280`) : `pages["/"]` avec `h1`, `h1Ligne`, `chapeau`, `sections[{ h2, genre, blocs }]` et `jsonld`, puis une page par commune (`type: "commune"`, `cible`) et les pages légales (modèle : `public/sites-demo/lestraque/contenu.json`).

Le seul rédacteur de site existant, `generateSiteContent` (`lib/ai.ts:1083`), rend l'ancien format v1 (`SiteContenu`, `:1039-1049`). Il **ne peut pas** servir : il faut une fonction nouvelle. On en reprend seulement les deux contrôles d'invention :
- `findFabrications(sortie, entree)` (`lib/ai.ts:1054`) : années, pourcentages, prix, labels, superlatifs ;
- `detecterCapacitesNonDeclarees(texte, profil)` (`lib/ai/antiFabrication.ts:146`) : « je me déplace », « sous 48 h »…

Les modèles de métier au format v2, avec les marques `{entreprise}` et `{ville}`, sans chiffre ni label ni superlatif, sont écrits par 025-02 (menuisier) et 025-11 (plombier, électricien, couvreur) dans `maquettes/modeles/<métier>/contenu.json`.

`scripts/site-qa.mjs` refuse les pages de commune creuses ou répétitives (`:566-569`). C'est la seule raison d'appeler un modèle de langage : varier le chapeau et l'introduction de chaque commune. **Tout le reste est déterministe.**

**La voix de l'artisan n'est jamais rédigée.** Prénom, nom, année, parcours, phrase signée et chiffres passent tels quels de `matiere.artisan` à `site.json`, par le générateur (025-03). Ils n'entrent pas dans `contenu.json`.

**L'appel au modèle est injecté.** Le modèle n'est joint que par `lib/agents/llm.ts` (plan §2.1, règle 3), module de la fiche 026-043, réservé à Claude Code (`creerLecteur('redacteur_site')`, Codex gpt-6-sol, qui rend `null` sans moteur). Le produit ne prête jamais sa clé. Tant que ce module n'existe pas, `--sans-ia`.

Réservée à Claude Code : consignes du rédacteur et contrôle d'invention (plan §6.4). Dépend de 025-02, 025-11 et de la fiche 13.

## Ce qu'il faut faire

1. **`lib/siteRedacteur.ts`**, `redigerContenuV2({ commande, artisan, modele, modelesSecondaires }, appel?)` → `{ contenu, rapport }` :
   - **pages** : l'accueil, une page `/<métier>-<commune>/` par commune de `commande.communes` et aucune autre, une page par métier secondaire (depuis son propre modèle ; modèle absent → `rapport.bloquant`), et `/mentions-legales/` et `/confidentialite/` ;
   - **pages légales rédigées à partir des faits** : entreprise, adresse, SIREN, assureur et numéro de décennale, hébergeur Vercel Inc., éditeur de la plateforme Presti, traitement des demandes du formulaire. Jamais le texte fictif de Lestraque ; aucun « démonstration » ni « fictif » ;
   - **marques** : `{entreprise}` et `{ville}` remplacées partout ; il n'en reste aucune ;
   - **prestations** : on ne garde du modèle que celles que l'artisan a déclarées (`matiere.prestations`, `artisan.services`, métiers secondaires), comparées sans accents. Aucune déclarée → `rapport.bloquant = 'prestations non déclarées'` ;
   - **rien d'avis** : ni avis, ni témoignage, ni note, ni étoile, ni citation d'un tiers ;
   - **l'appel**, pour les chapeaux et introductions des communes seulement :
     - le système décrit la tâche et impose une sortie JSON stricte ;
     - les faits passent comme **donnée**, entre `<donnees>` et `</donnees>`, sur le modèle de `blocProspect` (`lib/ai.ts:430`) ;
     - ni l'adresse e-mail, ni le téléphone, ni le SIREN ne sont envoyés ;
     - chaque sortie passe `findFabrications` et `detecterCapacitesNonDeclarees` contre le texte des faits ;
     - un rejet donne **un** second appel qui nomme les éléments refusés, puis la dégradation vers le texte du modèle ;
     - `rapport` liste les champs rédigés, les rejets et les dégradations.
2. **`scripts/commande-rediger.mjs <dossier-source> [--sans-ia]`** :
   - il lit `commande.json` (fiche 13) et le modèle du métier ;
   - il écrit `contenu.json` et `redaction.json` dans le même dossier ;
   - il branche `appel` sur l'export de `lib/agents/llm.ts` par import dynamique. Module absent : message « clé agents absente : rédaction sans IA » et `--sans-ia` ;
   - `rapport.bloquant` → code 3 ;
   - il refuse un dossier sous `public/` (code 2).
