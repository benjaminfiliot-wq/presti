# 025-04 — fermer la porte du site gratuit (migration 0093)

## Contexte

Le verrou `lock_artisan_privileges` (dernière définition : `supabase/migrations/0068_controle.sql:157-186`, aucune migration postérieure ne la redéfinit) empêche le navigateur de changer `plan`, `credits`, `slug`, `domaine`, etc. Il ne fige ni `site_active`, ni `site_tier`, ni `site_contenu`, ni `site_origine` (colonne ajoutée par `0088_site_commande.sql:76`). Les écritures légitimes passent déjà par le serveur (`app/api/donnees/route.ts:118`, `lib/purgeComptes.ts:102`, `app/api/controle/sites/[id]/route.ts:83`).

Réservée à Claude Code : schéma et droits (`CLAUDE.md:23`).
