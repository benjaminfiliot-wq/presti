## Rectifications transversales

- **Élément faux** : une vidéo qui affirme un paiement de 1 300 € ne montre pas une pièce comptable ; `pubs` n°5, image t000.0 et voix 0:00. Dire « affirme » dans les usages Presti.
- **Élément déformé** : l’onglet « Ad Library API » à t014.0 dans Hugo ne prouve pas, seul, que la même API livre toutes les pubs commerciales et tous les champs voulus ; conserver cette condition dans les fiches 026-072.
- **Manque** : les prix de bundles d’androoagi à t136.0 et t144.0 sont des pages externes, pas une recommandation d’achat pour Presti. Le registre doit séparer source et décision.
- **Manque** : le carrousel `aibymatty` et ses huit diapositives restent couverts par `pubs`, et `photography_by_raa` par `autres` ; aucune de leurs images ne fonde un achat ou une promesse de vente.
