# Inventaire final : Construction de boutique Shopify via Claude

## Méthode

1.  **Acquisition des outils d'IA** : Souscription à un abonnement Claude Pro et téléchargement de l'application de bureau [01:13 - 02:08].
2.  **Installation de l'environnement de développement** : Téléchargement et installation de Visual Studio Code (VS Code) [02:37 - 03:09].
3.  **Création de la boutique** : Ouverture d'un compte Shopify via une offre promotionnelle [03:09 - 03:46].
4.  **Choix du thème** : Sélection et installation du thème gratuit « Dawn » depuis le Shopify Theme Store [04:02 - 04:17].
5.  **Configuration de l'espace de travail** : Création d'un dossier local dédié sur l'ordinateur via VS Code [05:03 - 05:19].
6.  **Ouverture du terminal** : Lancement de l'interface de commande de l'ordinateur [05:28 - 05:44].
7.  **Installation du Shopify CLI** : Installation de l'outil pour permettre la modification des thèmes localement [05:52 - 06:07].
8.  **Authentification technique** : Connexion dans le terminal via le mot de passe de l'ordinateur [06:23 - 06:46].
9.  **Préparation du thème** : Ajout d'une copie du thème Dawn dans l'interface Shopify [07:11 - 07:18].
10. **Téléchargement du thème** : Utilisation du terminal pour récupérer le thème localement [07:33].
11. **Liaison Terminal/IA** : Connexion du terminal à Claude via Visual Studio Code [08:04].
12. **Vérification de la connexion** : Utilisation de la commande `shopify theme list` pour confirmer l'accès aux thèmes [08:37].
13. **Installation de l'extension Cloud Code** : Installation via VS Code [09:25].
14. **Intégration Shopify CLI dans VS Code** : Installation via un prompt envoyé à l'IA [09:58].
15. **Vérification NPM** : Exécution de la commande `npm version` [10:13].
16. **Connexion finale** : Liaison de la boutique à Claude Code via le nom de domaine [10:21].
17. **Synchronisation des thèmes** : Vérification finale via la commande `Shopify Theme List` [10:44].
18. **Recherche concurrentielle** : Utilisation d'AutoDS pour identifier des boutiques performantes [11:23].
19. **Sourcing de niches** : Utilisation de l'outil Adpy/AdSpy pour trouver des boutiques de beauté [12:18].
20. **Modification esthétique par prompt** : Changement de la couleur du bouton « ajouter au panier » via VS Code [14:18].
21. **Ajout d'éléments de confiance** : Demande d'ajout de trois badges de réassurance via prompt [15:17].
22. **Insertion technique des badges** : Placement des badges (PayPal, Visa, Money Back) sous le bouton d'achat [15:33 - 16:44].
23. **Reproduction de structure de page** : Identification d'un modèle sur AutoDS, génération du framework par Claude Code, transfert vers VS Code et intégration du code HTML [16:44 - 18:12].
24. **Clonage visuel** : Capture de la page cible en PDF via Web FireShot, transmission du PDF à l'IA dans VS Code, et génération automatisée du CSS global et des sections [18:12 - 20:14].
25. **Déploiement Shopify** : Poussée des fichiers sur le thème et assignation du modèle de page dans l'administration Shopify [20:14 - 22:35].
26. **Personnalisation textuelle** : Modification des textes via l'interface Shopify [21:19].
27. **Mise en place du marketing** : Création d'un compte Omnisend et installation de l'application sur la boutique [22:35 - 23:28].
28. **Configuration des campagnes** : Création de réductions spéciales (ex: été) [23:42].
29. **Automatisation des relances** : Mise en place d'un workflow d'abandon de panier [23:49].
30. **Génération de séquence d'emails** : Utilisation de l'IA « Lia » pour rédiger 3 emails [24:53].
31. **Séquençage temporel** : Programmation des envois à 1h (bienveillant), 24h (preuve sociale) et 72h (urgence) [25:16].
32. **Intégration Omnisend** : Copie manuelle des textes générés par l'IA vers la plateforme [25:31 - 25:47].
33. **Personnalisation des options produit** : Capture d'une structure existante, téléchargement de l'image dans Claude Code et reproduction de la structure des options [26:10 - 26:49].
34. **Implémentation des offres groupées** : Création de cartes d'options (ex: achetez-en 2, 3 ou 4) sans ajout de variantes manuelles [27:34 - 27:43].
