# _Index-Validation

> Prouver la demande **avant** de coder. Méthode complète dans le skill `saas-problem-finder` → `references/validation.md`. Règle : la 1re "construction" n'est jamais du code.

## L'échelle (du moins cher au plus cher)

1. **Signaux de demande** (gratuit) — concurrents payants, plaintes Reddit, avis 2★, gigs Fiverr.
2. **Parler à 5-10 personnes de la niche** (Mom Test) — le plus important. On parle de LEUR passé, pas de notre idée.
3. **Smoke test** — landing page + liste d'attente, mesurer le taux d'inscription sur trafic ciblé.
4. **MVP concierge** — livrer le résultat à la main avant d'automatiser.
5. **Pré-vente** — faire payer / obtenir un engagement ferme AVANT que le produit existe. Le seul vrai signal.

**Toujours définir GO/KILL chiffré AVANT chaque test.**
