# _Index-Recherche

> Le sourcing brut : tout ce qu'on récolte en cherchant des problèmes. Le meilleur signal, c'est **un budget déjà dépensé** (outil payant, freelance, salaire). On range ici les trouvailles avant d'en faire des fiches problème.

## Pistes à miner (voir la méthode dans le skill `saas-problem-finder`)

- **Review mining** — avis 2-3★ sur G2, Capterra, Trustpilot, App Store, Play Store → ce que les gens détestent alors qu'ils paient déjà.
- **Reddit** — `site:reddit.com "j'aimerais un outil"` / `"is there a tool that"` + niche.
- **Marketplaces freelance** — Upwork / Fiverr / Malt : gigs répétitifs = demande solvable à automatiser.
- **Communautés** — groupes FB, Discord, Slack de la niche : questions qui reviennent chaque semaine.
- **Demande d'automatisation** — templates Zapier/Make/n8n populaires.
