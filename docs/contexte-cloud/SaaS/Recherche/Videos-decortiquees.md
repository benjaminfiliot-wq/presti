## V1 — Rigueur technique / qualité / données structurées (2 min 13)
**Ton/format** : talking-head, expert qui « décortique tout ».
**Transcription reconstituée** : « …règle qui peut… quand ton code de[…] **corrigé automatiquement** voilà… **ton code doit être**[…] c'est exactement… **riches résultats**… faisais avec les **données structurées**… parce que **l'erreur en ligne elle est très très chère**… je décortique tout. »
**Ce que ça veut dire pour nous :**
- Coder **proprement** — surtout **PAS de vibecoding** (Benj insiste). Une erreur en prod coûte cher.
- Le code doit être **vérifié / auto-corrigé** (linting, tests, revue).
- **Données structurées (schema.org / JSON-LD)** → apparaître en **rich results** dans Google.
**Actions Presti :** ✅ schema FAQPage sur `/faq` + SoftwareApplication sur la landing · discipline de vérif systématique (build → deploy → check in-browser) · [[benj-corrections-incrementales]].
