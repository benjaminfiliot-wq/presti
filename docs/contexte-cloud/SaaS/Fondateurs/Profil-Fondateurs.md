## ⚠️ Contraintes → conséquences stratégiques (à respecter dans la chasse d'idées)

Ces contraintes ne sont pas des détails : elles **filtrent** directement quels problèmes valent le coup.

1. **0 € + acquisition sur Reddit (value-first)** → il faut viser un problème dont les clients :
   - se regroupent dans **un ou plusieurs subreddits actifs et identifiables** (si pas de communauté
     Reddit vivante pour cette cible → notre canal ne marche pas) ;
   - sont plutôt du **B2B** ou des **pros/indépendants qui gagnent de l'argent**, et qui ont **déjà un
     budget**.
   Un produit qui a besoin de pub payante ou d'une grosse audience pour décoller = incompatible.
   Note : Reddit sert **doublement** — sourcing des problèmes (pain mining dans les subs) ET acquisition.
2. **Benj code tout avec l'IA** → le MVP doit être **buildable en quelques semaines** par une personne
   assistée par l'IA. On écarte ce qui demande de la R&D lourde ou une précision critique.
3. **On veut du récurrent** → privilégier les problèmes qui **reviennent** (hebdo/quotidien), pas les
   besoins one-shot.
