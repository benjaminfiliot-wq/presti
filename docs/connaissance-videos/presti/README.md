# Videos Presti lisibles dans Git

Sources originales sur le PC : `C:/Users/benja/Documents/presti`. [Index](index.json) contient taille, empreinte, duree, resolution, codecs et piste audio.

Chaque publication possede une planche de huit images horodatees au format paysage et son texte editorial original ; les trois variantes disposent de leurs metadonnees. Les demonstrations et cinq captures representent les autres usages. Une planche est un echantillon visuel, pas une verification complete du film.

Les textes associes sont des scripts/editoriaux ecrits, pas une transcription obtenue par ecoute. [Historique des voix](VOIX-HISTORIQUE-SOURCE.md) rapporte le remplacement des dix premieres voix par musique ; [script de voix](VOIX-SCRIPT-SOURCE.mjs.txt) conserve le texte prepare. Aucun ASR ni ecoute humaine nest revendique.


Les publications 11 a 20 sont documentees dans [les textes de la deuxieme serie](PUBLICATIONS-SERIE-2-TEXTES-SOURCE.md). [Scenes ecrites](PUBLICATIONS-SCENES-SOURCE.mjs.txt), [musique et historique](MUSIQUE-SOURCE.md).
